# JAMA八类图表阅读与绘制

## 八类图的关键口径

| 主题 | 图中应有的内容 | 最容易误读的地方 |
|---|---|---|
| Kaplan–Meier | 阶梯估计、删失标记、在险人数、时间单位 | Log-rank检验不是校正后HR；生存概率与累积风险区分 |
| 森林图 | 估计值、区间、参考线；真实Meta才有合并菱形 | OR/RR/HR用适当比值尺度；方块大小需有权重依据 |
| 试验流程 | 筛查、排除及原因、分配、随访、分析人数 | 人数流向守恒；不能用观察性队列冒充随机分配 |
| 限制性立方样条RCS | 参考暴露、曲线、区间、数据覆盖 | 总体与非线性P值不同；少数据尾部不外推 |
| 箱线与散点 | 中位数、四分位、须定义、样本量 | 图上的圆点可能仅为离群值，不能都解释为原始观测 |
| 累积发生率CIF | 目标事件、竞争事件、时间与估计方法 | 存在竞争事件时不能直接把1−KM当CIF |
| 预测模型 | ROC/PR、校准、决策曲线与验证样本 | AUROC不等于校准或临床价值；训练表现不代表外部验证 |
| 目标试验模拟 | 入选、策略、分配、time zero、随访与分析 | 方案对照表是设计图解；效果曲线不能替代时间对齐 |

## 处理原图与教学图

用户要真实期刊图时，先查文章属于主刊还是子刊，再核对题名、年份、DOI、图号和图注。阅读方法段后才能解释删失、竞争风险、调整变量、区间及样条参考值；索引中出现题名不等于读过全文。

原图裁切保留图例、坐标、分母和必要图注；标明裁切或重排。截图不升级为原创图，不通过生成模型重画数值。转载、改编与教学使用按实际许可分别处理。

原创示意只用于解释图型，显著标注“教学示意，非研究结果”；不要把模拟值、虚构P值或假参考文献放入正式结果。若用户要分析图，必须使用实际数据/模型结果。

## 输出一段可用的读图说明

依次说明研究问题、坐标与图例、主要比较和不确定性、可支持的判断、不能从本图判断的问题。避免把所有图都写成“显著提升”或用一条曲线宣布因果关系。
