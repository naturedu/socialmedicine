# 🧭 方法逻辑地图：从问题走到模型

## 第一步：你希望得到什么

| 研究目的 | 下一步 | 常见路线 |
|---|---|---|
| 描述分布/差异 | 样本能代表谁？结局怎么测？ | 抽样、标化、描述与区间 |
| 解释政策/干预效果 | 谁接受了什么策略？何时开始？ | TTE、PSM/IPW、DID/SDID、IV、RDD |
| 预测未来结局 | 预测时点有哪些信息？如何独立验证？ | 正则化、ML、校准、净获益 |
| 探索分型与机制 | 特征相似性或构念如何定义？ | 聚类、潜类别、定性、SEM/fsQCA |
| 综合既有证据 | 分析单位是原始研究还是综述？ | Meta、网状Meta、伞状/范围综述 |
| 资源配置与长期决策 | 状态、历史、容量与互动如何运转？ | Markov、微观、DES、SD、ABM与PSA |

## 第二步：把目标写成一句话

对〔目标人群〕，在〔时间窗〕比较〔策略A/B〕，估计〔风险差/均值差/ATT等〕；或在〔预测时点〕预测〔未来结局〕。不要把“找影响因素”“做一个高级模型”作为完整目标。

## 第三步：检查数据与设计

- 暴露和结局谁先发生？是否有可核验的基线与处理日期？
- 分析单位是患者、医院、城市、文件还是综述？重复/聚类发生在哪里？
- 结局支持集、缺失、失访、竞争事件和抽样权重是什么？
- 因果识别依赖什么：条件可交换、平行趋势、阈值连续性还是有效工具？哪些假设不能直接检验？

## 第四步：沿着合适的分叉前进

| 情境 | 详细框架 |
|---|---|
| PSM、匹配、IPW、熵平衡 | [目标→混杂→重叠→平衡→推断](propensity-score-skill.md) |
| 同时政策/交错政策/少量处理城市 | [基础DID](did-skill.md) · [交错DID](staggered-did-skill.md) · [SDID/DML](advanced-causal-inference-skill.md) |
| 二元、费用、计数、面板与空间数据 | [六步计量模型选型](econometric-modeling-skill.md) |
| 无标签探索患者或机构分型 | [特征→距离→算法→类数→稳定性](clustering-analysis-skill.md) |
| 观察数据评价治疗策略 | [先写目标试验协议](target-trial-emulation-skill.md) |
| 多干预比较/多综述总结 | [网状Meta](network-meta-analysis-skill.md) · [伞状综述](umbrella-review-skill.md) |
| 模型性能与政策情景 | [蒙特卡洛](monte-carlo-simulation-skill.md) · [模拟选型](simulation-models-skill.md) · [个体微观模拟](microsimulation-studio.md) |

## 第五步：让诊断决定能解释多远

平衡好不等于无混杂；趋势检验不显著不等于假设已证明；轮廓系数高不等于天然亚型；高AUC不等于临床获益；排序靠前不等于高确定性最佳干预；模拟重复多不等于结构正确。

## 最后交付一张模型说明卡

研究问题｜估计目标｜数据结构｜识别假设｜模型与代码｜必要诊断｜结果尺度与区间｜敏感性｜适用边界。

> 请按这张逻辑地图为我的研究选方法。先指出信息缺口，再比较有依据的路线，不按复杂程度和P值挑模型。
