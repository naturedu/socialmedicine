# 声明、披露与最终检查

## 两个问题分别回答

每项声明都先问“事实是什么”，再问“本刊要求放在哪里”。全部投稿材料可能需要某项信息，但不代表 cover letter 必须重复它。完整的期刊差异和核验范围见 [期刊要求](journal-guidance.md)。

| 项目 | 必须有的事实依据 | 常见错误 |
|---|---|---|
| 非同时投稿 | 作者明确确认当前无其他期刊在审 | 根据旧信自动沿用，或把尚未撤稿视为已结束 |
| 原创性/既往发表 | 当前稿件、预印本、摘要、相关论文的真实传播状态 | 有预印本却写“从未以任何形式公开” |
| 全体作者同意 | 对当前提交版本和目标期刊的明确确认 | 把作者出现在名单中当成同意证据 |
| 作者资格 | 作者贡献与适用准则 | 因是医学期刊就自动写所有作者满足 ICMJE |
| 利益冲突 | 作者确认/披露材料，含非经济关系 | 未提供就写 none；把无基金等同无利益冲突 |
| 资助 | 资助方、项目编号与实际支持关系 | 把其他稿件基金号或伦理号混入 |
| 伦理审查 | 委员会决定、适用对象及范围 | 有编号就推定批准日期或全部研究获批 |
| 知情同意 | 同意文件或伦理委员会明确决定 | 伦理批准直接等同已获同意/免除同意 |
| 注册 | 注册记录、日期、研究开始时间 | 有编号即称前瞻注册 |
| 数据/代码 | 实际可用性、访问条件、可公开链接 | 链接存在就说全部数据开放；把演示页当存储库 |
| AI 使用 | 实际用途与期刊当前政策 | 忽略适用披露，或虚构 AI 参与数据分析 |
| 推荐/回避审稿人 | 期刊允许、真实身份与利益关系依据 | 捏造邮箱、默认所有期刊都收这类信息 |

## 伦理与同意必须分开

至少区分以下状态：

- 伦理委员会批准研究；记录真实名称与决定编号（如有）。
- 有权机构决定豁免伦理审查；按原决定措辞，不自动改成 approved。
- 有权机构决定免除取得知情同意；并不等于免除伦理审查。
- 特定研究不适用某项要求；必须有类型及规则依据，不凭“回顾性/匿名数据”直接推断。
- 当前资料不足；放入待核实项。

批准日期、决定生效期和研究数据覆盖期不是同一个日期。编号外观不能证明日期。信中是否需要写这些细节由目标刊和本次投稿情况决定。

## 预印本、会议摘要和同源稿件

保留真实披露，不用笼统“从未发表”掩盖传播状态。核查本刊如何定义 prior publication、是否接受预印本、需要链接/DOI/许可还是补充附件。会议报告、会议摘要与完整期刊论文分别处理。

同一数据的其他论文应说明研究问题、样本或结果的重叠与差异；披露并不能自动证明不存在重复发表，需要实质比较。不替作者宣称“完全独立”，除非材料支持。同行评审中的稿件及保密材料只通过获准路径向编辑提供，不随公开示例发布。

## 条件式英文句库

以下仅供在事实已确认、期刊要求适用时采用。不得整段无条件粘贴。

| 事实已确认的场景 | 可调整句式 |
|---|---|
| 当前不在其他期刊审理 | This manuscript is not under consideration by another journal. |
| 当前版本已获全体作者同意 | All authors have reviewed and approved this submission. |
| 确认没有需披露的冲突 | The authors declare no competing interests. |
| 实际存在需说明的关系 | [AUTHOR/ROLE] reports [RELATIONSHIP]. Full disclosures are provided in [REQUIRED LOCATION]. |
| 有预印本且本刊允许 | A preprint is available at [PERSISTENT LINK]. [EXPLAIN MATERIAL DIFFERENCES IF REQUIRED]. |
| 有相关论文 | A related [ARTICLE/MANUSCRIPT] examines [DISTINCT QUESTION] using [OVERLAPPING MATERIAL]. [DESCRIBE OVERLAP AND REQUIRED ENCLOSURE]. |
| 已获伦理批准 | The study was approved by [COMMITTEE] ([REFERENCE, IF APPLICABLE]). |
| 委员会明确免除同意 | The requirement for informed consent was waived by [AUTHORIZED BODY]. |
| 注册事实已核对 | The study was registered at [REGISTRY] ([IDENTIFIER]). |

有真实披露则具体说明，不使用“无冲突”句。没有必要放进信里的信息，留在投稿系统或稿件要求的位置。对未知项，不写“We confirm ...”，也不让一串占位符看起来像已完成的声明。

## 最终逐项核对

### 事实一致性

- 题名、文章类型、期刊全名、特刊、稿号与当前投稿对象一致。
- 样本、时间窗、比较组、主要结果、单位、区间与最终稿件一致。
- 关联/因果、内部/外部验证、有效性/可接受性等标签准确。
- 主要贡献明确，未虚构优先性、代表作、邀请或既往沟通。
- 作者署名、通讯角色、单位、联系信息来自当前确认材料。
- 声明内容和放置位置已核查；无相互矛盾的原创性与预印本表述。

### 投稿阶段和附件

- 初投不称“revised manuscript”，换刊不假装新刊曾审稿。
- 返修概括与主稿、回复信、补充资料中的实际修改相符。
- 提及的附件已存在且版本正确；不要声称已上传实际未上传的材料。
- 不把技术检查、编辑处理或审稿人邀请阶段描述为外审已完成。

### 可用性

- 日期符合实际用途；无旧刊名、旧稿号、旧署名、教学注释和未替换字段。
- 文件可编辑、文本可选择；PDF 实际可打开，徽标和署名没有被挤到第二页。
- 信件内容与交付说明分开；不含内部文件路径、聊天引用和修改过程。

## 如何报告核验范围

用具体事实而非总分：“按提供的最新正文与表 2 核对；目标刊作者指南已于 [DATE] 阅读；作者批准与预印本状态待确认。”

“可提交稿”仅表示已完成本任务所需的材料与格式核对，不表示编辑会接受。遇到关键冲突可交付待确认稿，明确指出一两项真正阻碍提交的内容；不要因可省略信息缺失而扣留整封信。
