# 输入、版本与证据核对

## 最小信息集

先读已有材料，再询问缺口。初稿不要求用户一次性回答长问卷。

| 信息 | 优先来源 | 不完整时的处理 |
|---|---|---|
| 目标期刊、文章类型、特刊 | 本轮要求、官网、正式邀请 | 期刊不明时先给通用稿并问目标刊；不猜子刊 |
| 完整题名 | 当前稿件标题页 | 与旧信不同，使用用户确认的新版本 |
| 投稿阶段 | 本轮要求、编辑决定信、转投记录 | 区分首次投稿、换刊、受邀修回、技术修改 |
| 研究问题、设计、数据/人群 | Methods、协议、分析说明 | 只读摘要时标注证据范围 |
| 关键结果 | Results、最终表图及其脚注 | 数字冲突暂停该数字，先完成其他段落 |
| 创新/增量 | Introduction、Discussion、可靠对比文献 | 缺少比较检索时写具体贡献，不声称首创 |
| 作者和通讯作者 | 当前标题页、用户确认 | 不把第一作者自动当通讯作者 |
| 声明 | 当前声明页、编辑要求、明确作者确认 | 按“已确认/缺失/冲突/不适用”记录 |
| 日期和署名 | 用户本轮指定；否则当前日期和确认身份 | 归档/复原旧信时保留原日期；新提交不沿用旧日期 |

英文标题保持稿件用词与大小写一致，除非用户授权改题。作者名单、单位英文名称、通讯作者顺序和多个通讯作者的处理按稿件与投稿系统一致。

## 事实来源的强弱

1. 当前稿件与对应的最终表图/统计输出；若互相冲突，先解决，不能以排序替代核实。
2. 用户明确确认的信息与正式编辑通知。
3. 已核验的期刊官网规则、公开记录或注册信息。
4. 旧投稿信和历史讨论仅作线索；不能覆盖新稿件。
5. 模板和示例不提供任何作者事实。

历史对话只检索与当前稿件或用户写作偏好相关部分。可学习结构偏好、修订方向和已确认规则；不能把别篇论文的样本、伦理编号、作者批准或经历迁移过来。

## 建立小型证据表

复杂任务用工作表记录“将写入的论断—来源位置—支持程度—允许措辞—冲突”。例如：

| 候选表述 | 实际证据 | 决策 |
|---|---|---|
| 政策降低了成本 | 只有单期横断面组间差异 | 改为费用与政策暴露相关；不能据此归因 |
| 独立外部验证 | 训练/验证人群来自同一批样本随机划分 | 改为内部验证，核实划分方式 |
| 所有人均签署知情同意 | 有伦理批准，但未读知情同意信息 | 暂不确认；伦理批准与同意分开核实 |
| 无任何相关发表 | 同一数据已有相关论文 | 检查重叠并按期刊要求披露；不能简单否认 |

## 数字逐项核对

- 分清纳入人数、分析人数、观测次数、事件数；多波次数据不能把 person-wave 当独立受试者。
- 区分 OR/RR/HR、回归系数、均值差、风险差和百分比变化；不把 OR=0.80 自动写成风险降低 20%。
- 绝对变化和相对变化不互换：10% 到 8% 是减少 2 个百分点，或相对减少 20%。
- 保留参照组、时间窗、单位和区间；同一句估计值与区间来自同一模型。
- 优先主要结果，避免用更漂亮的亚组结果冒充主要发现；统计不显著不等于没有效应。
- 不为满足模板补造置信区间、P 值或精确数字；定性研究和概念论文不强塞统计量。
- 信中减少数字后，仍须保留解释方向所需的单位、参照和不确定性。

## 缺口如何表达

可省略：不要求提供的编辑姓名、学位、电话、代表作。

可起草但不可标为最终：未确认的原创性/非同时投稿、作者批准、利益冲突、信中必填的伦理或相关稿件信息。

需要先澄清：目标刊身份冲突，用户要求使用与稿件不一致的结果，或材料无法判断是首次投稿还是受邀修回。

把待核实问题放在信外，短而具体，例如：“当前表 2 与摘要的分析样本数不同，请确认采用哪一版。”不要在正式信里放工作过程、内部文件路径或聊天记录。
