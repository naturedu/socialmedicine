# 学术期刊 Cover Letter

把稿件中已证实的贡献写成编辑能够快速判断的投稿理由。默认用中文沟通、按目标期刊语言写正式信；用户指定的语言、结构和长度优先。适用于医学、公共卫生、卫生政策与社会科学；其他领域沿用证据与适配逻辑。

## 先识别任务

| 请求 | 处理方式 | 按需读取 |
|---|---|---|
| 从稿件起草 / 完整重写 | 核对输入，建立贡献主线，再成文 | [输入与证据](references/intake-and-evidence.md)、[三段式写作](references/editorial-argument.md) |
| 只改日期、称谓、句子或语言；明确仅替换刊名 | 只完成指定修改；不自动开展整封信重写或投稿检查 | 通常无需额外读取；明显实质错误可另行简短提示 |
| 换刊 / 出版社转投 | 核对新刊、重新论证适配、处理旧刊残留 | [转投与返修](references/retarget-and-revise.md) |
| 修回投稿 / 技术退回 | 概述实际完成的改动，区别逐条回复 | [转投与返修](references/retarget-and-revise.md) |
| 不确定创新点或结果如何写 | 区分研究设计、结果和可支持的结论 | [按研究类型选证据](references/study-designs.md) |
| 投稿就绪检查 | 查最新官网，核实声明及最终版本一致性 | [期刊要求](references/journal-guidance.md)、[声明与终检](references/declarations-and-checks.md) |
| 教学模板 / 校徽信头 / 可编辑 Word | 正式稿与中文标注分开，核实身份和素材 | [格式与教学版](references/format-and-teaching.md) |

不要为了起草短信默认读取全部参考资料。完整起草通常需要写作、期刊、声明三个分支；研究类型和文件制作按需要补充。

## 工作流程

### 1. 锁定输入与版本

从用户给出的稿件、已有信件和明确相关的历史对话中提取，不要求用户重复提供已知信息。至少锁定目标刊全名/官网、文章题名、文章类型、投稿阶段、最新结果来源。只有旧信时可以改写，但不能宣称核对过全文。

新稿件/用户本轮更正优先于旧信和历史版本；明确更正已消解的旧错误直接修正，不重复确认。只有新信息仍无法消解的数字、设计、作者或声明冲突，才记录并询问关键一项，不自行选择“更好看”的版本。缺失项按重要性处理：可省略的省略，可继续的先起草，影响事实的用显著字段标明并列入待核实项。

### 2. 核对期刊要求

完整起草、改投或提交就绪核验时，查目标期刊官网的当前文章类型、作者指南和投稿入口；纯局部修改不自动启动此流程。确认 cover letter 是必需还是可选，以及字数、收件称谓、特殊声明和相关稿件要求。为要求建立“内容—放置位置—来源—日期”的映射；投稿系统、标题页、主稿和投稿信中的要求不能混为一谈。

官网无法访问时，说明未核验；不从旧模板推定现行规则。没有明确长度要求时，以一页、约 250–400 个英文词作为可调整的写作目标，绝不标成期刊硬性规定。编辑姓名不确定可用 “Dear Editors,”。精确区分同名近似期刊、主刊与子刊、出版社和特刊。

### 3. 组织三段式主体

默认使用以下三段，也可按官网或用户要求调整。问候、必要声明和署名可单列，不为保持三段而删掉必要事实。

1. **投稿信息与科学问题**：题名、文章类型、目标刊；用一句话点明尚未解决的问题。特刊只在确有信息时注明。
2. **研究贡献与关键证据**：简述设计/人群，选 1–2 个足以说明贡献的结果；讲清比已有证据多回答了什么。不是压缩复制摘要，不罗列全部分析。
3. **与期刊读者的关系**：指出具体读者、实际判断或研究问题，以及该结果能提供的证据；意义与研究设计相称。避免泛泛赞美期刊、以影响因子论证适配。

### 4. 写入已证实且需要的声明

原创性、非同时投稿、全体作者同意、利益冲突、伦理/豁免、注册、预印本及相关稿件均按实际情况和期刊要求处理。未知不等于没有；“稿件包含声明”不等于其内容已核实。模板中的确认句是条件句库，不能默认当作事实。

### 5. 交叉检查并交付

逐项核对题名、期刊、日期、作者角色、样本/事件数、效应方向、单位、区间、设计标签、附件和声明。修回信的“已完成”必须有实际修改依据。不能根据信件本身反证研究结论正确。

默认交付：

- **正式投稿信**：可直接复制；必要占位符显著保留，不能把带占位符的信称为最终版。
- **简短核验说明**：写明依据版本、官网核验范围、实质修改和仍待确认的事实。若用户只要求局部改动，仅报告相关信息。
- **文件**：用户要求时提供可编辑 DOCX；需要 PDF 时一并导出。使用实际可用的文档工具并检查最终版面。仅有纯文本时如实标注。

有缺失关键声明或事实冲突，标记“待确认稿”；全部必要项已核实、无占位符才可标记“可提交稿”。写好信件不等于向期刊投递；仅在用户明确要求实际提交时执行相应外部操作。

## 可复用材料

- [证据工作表](assets/evidence-worksheet.md)：复杂稿件、多版本或转投时使用；简单润色不强制填表。
- [条件式英文模板](assets/letter-templates.md)：首次投稿、换刊、修回；每段按证据重写，不机械替换期刊名。
- [完整合成示例与反例](references/worked-examples.md)：理解论证层次和证据边界；所有示例均为虚构练习，不能当真实数据或成果。

## 质量底线

- 不凭“顶刊语气”增强结论；关联不写成因果，模型性能不写成改善患者结局。
- 不虚构伦理批件、注册号、作者批准、联系信息、既往沟通、代表作或审稿人利益关系。
- “first”“largest”“practice-changing”需要可核实的比较证据；没有检索支持时改为描述具体增量。
- 用户要求“详实”主要落实到证据核对与修改说明，不自动把正式信扩写成多页背景综述。
- 教学版可以有中文说明和占位符；正式版清除注释、示范数字和教学标记。保留真实作者声音，不承诺影响录用率或通过 AI 检测。
