# 学术期刊 Cover Letter

把稿件中已证实的贡献写成编辑能够快速判断的投稿理由。默认交付**一页主信、三个连续正文段落、无分块小标题**；用中文沟通，按目标期刊语言写正式信。用户只需提供当前稿件与目标刊，先从材料提取信息，不要求重复填长问卷。适用于医学、公共卫生、卫生政策与社会科学。

## 一页纸成品与直接使用的 Word 模板

完整起草先读 [一页三段式具体范式](references/one-page-paradigm.md)。默认以 A4、11 pt 正文、约 220–320 个英文词为起点，包含日期、称呼、三段正文、必要声明和署名；这是本技能的成品偏好，不是所有期刊的硬性规定。正文写完后检查实际分页，不能靠小字号或删掉关键限定强行一页。用户或期刊有不同要求时按其要求调整。

- [一页填写版](assets/cover-letter-one-page.docx)：可直接编辑；页眉保留可替换的院徽位置，页脚保留可选相关代表作。
- [一页中文批注版](assets/cover-letter-one-page-commented.docx)：在日期、投稿身份、第二段科学论证、第三段适配、声明和署名处加入真正的 Word 批注。批注为通用写作提示，不冒充专家或院士意见。
- [一页完整范例](assets/cover-letter-one-page-example.docx)：采用明确标注的合成研究，演示填写后的连续书信；示例事实不得移入真实稿件。

请求 Word 时直接使用并填写附带 DOCX，不能只返回 Markdown 句库。需要 comments 时交批注版；实际投递使用完成事实替换后的无批注版本。模板内方括号、徽标说明和教学页脚必须填写或删除，不能将空模板称为可提交终稿。

| 换刊 / 出版社转投 | 核对新刊、重新论证适配、处理旧刊残留 | [转投与返修](references/retarget-and-revise.md) |

## 工作流程

### 1. 锁定输入与版本

从用户给出的稿件、已有信件和明确相关的历史对话中提取，不要求用户重复提供已知信息。至少锁定目标刊全名/官网、文章题名、文章类型、投稿阶段、最新结果来源。只有旧信时可以改写，但不能宣称核对过全文。

新稿件/用户本轮更正优先于旧信和历史版本；明确更正已消解的旧错误直接修正，不重复确认。只有新信息仍无法消解的数字、设计、作者或声明冲突，才记录并询问关键一项，不自行选择“更好看”的版本。缺失项按重要性处理：可省略的省略，可继续的先起草，影响事实的用显著字段标明并列入待核实项。

### 2. 核对期刊要求

完整起草、改投或提交就绪核验时，查目标期刊官网的当前文章类型、作者指南和投稿入口；纯局部修改不自动启动此流程。确认 cover letter 是必需还是可选，以及字数、收件称谓、特殊声明和相关稿件要求。为要求建立“内容—放置位置—来源—日期”的映射；投稿系统、标题页、主稿和投稿信中的要求不能混为一谈。

官网无法访问时，说明未核验；不从旧模板推定现行规则。一页目标包含整封主信，正文按必要信息调整；必需披露较多时先删冗余，仍放不下再说明页数取舍。编辑姓名不确定可用 “Dear Editors,”。精确区分同名近似期刊、主刊与子刊、出版社和特刊。

### 3. 组织三段式主体

默认使用以下三段，也可按官网或用户要求调整。问候、必要声明和署名可单列，不为保持三段而删掉必要事实。

1. **提交什么**：准确题名、文章类型和目标刊；有正式专题/特刊时给其准确名称。不把专题字段留在普通投稿信中。
2. **解决什么、增加什么证据**：科学问题 → 未解决的具体缺口 → 设计/人群 → 1–2 个关键结果 → 相比已有研究的具体增量。结果附必要单位与不确定性，避免照搬完整摘要。
3. **为什么适合本刊**：期刊确实覆盖的主题 → 具体读者 → 本文能帮助理解或判断的问题。说明可以怎样使用这项证据，不预测引用率、受众人数或录用结果。

上述名称仅用于解释段落功能，**不进入正式信作为小标题**。最后按 [自然学术表达](references/natural-academic-voice.md) 润色：用具体问题、动作和发现替代重大意义、突破性、完美契合等空泛评价；保留结论边界。

### 4. 写入已证实且需要的声明

原创性、非同时投稿、全体作者同意、利益冲突、伦理/豁免、注册、预印本及相关稿件均按实际情况和期刊要求处理。未知不等于没有；“稿件包含声明”不等于其内容已核实。模板中的确认句是条件句库，不能默认当作事实。

### 5. 交叉检查并交付

逐项核对题名、期刊、日期、作者角色、样本/事件数、效应方向、单位、区间、设计标签、附件和声明。修回信的“已完成”必须有实际修改依据。不能根据信件本身反证研究结论正确。

默认交付：

- **正式投稿信**：可直接复制；必要占位符显著保留，不能把带占位符的信称为最终版。
- **简短核验说明**：写明依据版本、官网核验范围、实质修改和仍待确认的事实。若用户只要求局部改动，仅报告相关信息。
- **文件**：用户要求时提供可编辑 DOCX；需要 PDF 时一并导出。使用实际可用的文档工具并检查最终版面。仅有纯文本时如实标注。

有缺失关键声明或事实冲突，标记“待确认稿”；全部必要项已核实、无占位符才可标记“可提交稿”。写好信件不等于向期刊投递；仅在用户明确要求实际提交时执行相应外部操作。

## 质量底线

- 不凭“顶刊语气”增强结论；关联不写成因果，模型性能不写成改善患者结局。
- 不虚构伦理批件、注册号、作者批准、联系信息、既往沟通、代表作或审稿人利益关系。
- “first”“largest”“practice-changing”需要可核实的比较证据；没有检索支持时改为描述具体增量。
- 用户要求“详实”主要落实到证据核对与修改说明，不自动把正式信扩写成多页背景综述。
- 教学版可以有中文说明和占位符；正式版清除注释、示范数字和教学标记。保留真实作者声音，不承诺影响录用率或通过 AI 检测。
