# 🏥 医保结算、临床登记与MEPS · 费用和事件数据

核验日期：2026-10-23。按人、就诊、费用明细和制度暴露构建可追溯分析层，区分结算费用与真实成本。


## 本次材料范围

已定位本机医保清洗库与多中心临床数据说明文件；本教程抽取通用结构与核验规则，不发布机构患者记录、未公开研究结果或私人路径。MEPS作为官方公共费用调查补充入口，与医保结算库、病历和登记系统分别解释。

## 四张核心表与连接

|表|最小单位|键和核验|
|---|---|---|
|person|一人|授权的匿名链接键、出生/性别等一致性；不可逆混淆规则由数据管理者保管|
|encounter|一次门诊/住院|就诊键、个人键、机构、入出院/就诊时间；转科转院与重复记录区分|
|cost_detail|一次收费/结算行|行键、就诊键、项目/药品、数量、单价、费用及冲退标记|
|policy|地区/机构—生效期间|发文、名义实施、真实结算切换、适用人群/服务及豁免规则|

先查每层唯一性、孤立记录、多重连接、合并后行数及费用总额守恒；join后总额膨胀通常提示明细或诊断多行交叉。诊断多项表用于疾病定义前先按就诊聚合，不能直接重复计费用。保留原币值、价格年、报销与自付口径；冲账、负值、补结算和跨月记账按业务规则审查，不能全部删作异常。

## 队列、事件与随访

第一次可观察就诊不必是真正新发病；需要入组前可观察窗口和疾病洗脱期才可提出相应新使用者/新发定义。出院后再入院需明确同日转院、跨院捕获、30/90天起止和死亡竞争。未见后续费用可能是未就医、转地区、退出参保或数据截断，不能全部当健康/零成本。

临床结局应区分检验原值、诊断代码、人工核实与算法派生；同次住院的末次检验不能当入院预测因子。病情严重程度、转诊及医院选择可能同时影响支付方式和结局；复杂模型不能替代可识别比较。

## 政策评估与费用模型

DRG/DIP、长护险、家庭病床等政策的启动时间按结算/供给实际切换核对，允许机构/人群例外。做交错DID需处理不同批次、对照支持、时间窗与聚类层级；只有一家医院且一时点可考虑ITS/CITS的条件，而非虚构多地区DID。政策可能改变编码或报销分类，先检验表面病例结构变化是否来自编码。

大量0费用考虑两部模型；正偏费用可比较适当GLM与标准化边际均值；计数结局考虑暴露时间和过度离散。报告总费用、自付和支付方支出，避免把某一方节约等同社会成本节约。人年变化与名义费用变化分开。

## MEPS选型入口

从AHRQ核对所需家庭、保险/雇主或提供方组件，确认年度/纵向文件、个人/事件键、调查权重、费用构造和回顾期。未经文档验证不要把调查报告的服务费用写成医院全成本。跨年度、跨面板连接需查该产品说明；本次仅核对官方入口，未导入MEPS微观文件。

## 🧺 先把数据放进正确的小篮子

建立文件清单：`study / release / module / wave / visit_date / unit / key / source / permission`。文件名中的版本字母、下载年份和访谈波次分开。原始文件只读；另存标准化层和分析层。先输出字段名、标签、值标签、缺失码和连接诊断，再决定变量能否使用。

每个分析变量至少记录：概念、原题、来源变量、适用人群、回顾窗口、单位、跳答路径、特殊码、代理回答、派生公式、可用波次、权重及核验状态。不得只凭中文列名判断值域或方向；`weight`在多份表中是体重。

## 从问题到估计的顺序

1. 写清目标人群、暴露/政策、比较组、结局和时间零点。区分人群患病比例、个体内变化、预测准确性和政策效应。
2. 画样本流：原始入样→年龄/资格→完成访谈→完成测量→连接随访→分析样本。死亡、失访、跳题、拒答、未测量分别记，不统一改成0。
3. 描述研究所需字段在每波的可用性。两波数据最多支持一次变化；多波轨迹需要足够重复观测、可比较测量与合理类数。
4. 按估计目标选择横断面、纵向或特定组件权重；权重不能凭变量名相似借用。失访加权需要可解释的响应模型和正值性诊断。
5. 面板FE估计的是个体内关联；PSM不能消除未测混杂；交错DID还需真实政策起始、前期趋势和有效对照；TTE需对齐资格、分组及随访起点。
6. 保留未加权人数、加权估计与区间。重复测量、家庭和地区依赖按设计处理；缺失值插补与抽样设计的结合需写明方法，避免把插补当作增加独立样本。
