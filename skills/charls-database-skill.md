# 🌱 CHARLS · 中国健康与养老追踪调查

核验日期：2026-10-23。中老年健康、经济与家庭追踪；原始模块、Harmonized与第三方清洗版分别建立版本清单。

## 已核对的字段与使用边界

|概念|本次材料中的字段/题目|核对后怎样使用|
|---|---|---|
|家庭病床|2018 EH005_W4 多选中的第4项|题前限制60岁及以上；先判断资格、整题是否回答、是否选中及“都没有”，再派生指标；原始落盘列名需另查|
|长护服务费用|EH003_W4_1、EH003_W4_2|过去一月总支出和保险支付分开；先核对进入该模块的路径|
|肾标志物|2011 newcrea / cystatinc；2015 bl_crea / bl_cysc|为本机材料核对的名称；核实单位、校准、采样日期及子样本权重，不能推广为每波都有|
|Harmonized疾病|r1hibpe、r3hibpe等|医生诊断自报；后续回答回填、未知和跳答处理须查所用版本|
|认知|2018与2020定向、减7、画图及词表|题号、错误码与呈现程序改变；逐分域对照后再形成共同项目集合|

本机清洗溯源发现部分人口学或日期使用后波修正、社区众数或区间中点填补。做基线预测时应回到基线可得信息，另保留“后期修正/插补”标记；死亡年月中点不能假装精确事件日。上述属于本次文件版本审计，不能概括为所有官方产品都有该处理。

### 家庭病床与长护险如何接起来

先分清“服务使用”“保险参保/待遇”“地区制度供给”。EH005_W4第4项只表示相应服务报告，不直接测量建床日期、住院替代、支付比例或政策落实。为需求匹配研究建立：年龄资格→ADL/IADL需要→服务使用→费用/自付。若实际有政策地区和实施日期，再另建地区—月政策表，查试点名单、启动时间、待遇资格和调查访谈时间。2018单波服务题无法单独支撑政策前后变化。

### 数字使用与认知的测量核验

本机问卷审计显示2015、2018和2020的词表轮数、读/看呈现程序有差异；2018画图错误/未评估编码与2020也不同。不能把“拒答/身体不能测/不知道/答错”全部记0。可先比较共同定向与减7项目，再单列词表成绩；若构造共同项目总分，给出题级计分表、完整性标准及去画图敏感性，不将自建分数称为临床痴呆诊断。

### 最小可行性检查

做一张“波次×模块×资格×有效观测”表。慢病结局明确自报诊断、治疗、体测和实验室定义；一次低eGFR只能按测量定义描述，不能仅凭该值断言慢性持续异常。照护时长须核对是照护者/被照护者、每周还是每月、首位还是全部照护者，不能把家庭转移金额当照护时间。


## R与Stata：标准化层的最小接口

以下变量名是**分析层约定**，不是原始数据库通用字段。必须先完成题级映射。若没有所需设计变量，先回查官方设计文件，不能任意生成PSU或权重。

```r
# d: id=字符个人键, year=实际访谈年, y=已核对结局, x=预定协变量
stopifnot(!anyNA(d$id), !anyDuplicated(d[c("id", "year")]))
d <- d[order(d$id, d$year), ]
# 纵向条件关联；不自动等于政策因果效应
m <- fixest::feols(y ~ x | id + year, cluster = ~id, data = d)
summary(m)
# 按复杂抽样作描述应另用对应设计与权重，而非仅cluster=id。
```

```stata
* id_s 是字符键，pid 仅作当前数据内面板编码，不输出映射。
assert !missing(id_s, year)
isid id_s year
egen long pid = group(id_s)
xtset pid year
xtreg y x i.year, fe vce(cluster pid)
* 单波数据不运行此面板流程；先选择合适的survey描述/横断面模型。
```

## 🧺 先把数据放进正确的小篮子

建立文件清单：`study / release / module / wave / visit_date / unit / key / source / permission`。文件名中的版本字母、下载年份和访谈波次分开。原始文件只读；另存标准化层和分析层。先输出字段名、标签、值标签、缺失码和连接诊断，再决定变量能否使用。

每个分析变量至少记录：概念、原题、来源变量、适用人群、回顾窗口、单位、跳答路径、特殊码、代理回答、派生公式、可用波次、权重及核验状态。不得只凭中文列名判断值域或方向；`weight`在多份表中是体重。

## 从问题到估计的顺序

1. 写清目标人群、暴露/政策、比较组、结局和时间零点。区分人群患病比例、个体内变化、预测准确性和政策效应。
2. 画样本流：原始入样→年龄/资格→完成访谈→完成测量→连接随访→分析样本。死亡、失访、跳题、拒答、未测量分别记，不统一改成0。
3. 描述研究所需字段在每波的可用性。两波数据最多支持一次变化；多波轨迹需要足够重复观测、可比较测量与合理类数。
4. 按估计目标选择横断面、纵向或特定组件权重；权重不能凭变量名相似借用。失访加权需要可解释的响应模型和正值性诊断。
5. 面板FE估计的是个体内关联；PSM不能消除未测混杂；交错DID还需真实政策起始、前期趋势和有效对照；TTE需对齐资格、分组及随访起点。
6. 保留未加权人数、加权估计与区间。重复测量、家庭和地区依赖按设计处理；缺失值插补与抽样设计的结合需写明方法，避免把插补当作增加独立样本。
