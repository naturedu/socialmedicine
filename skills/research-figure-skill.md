# 科研数据图与多面板排版

## 先确定图的论证任务

用一句话写出图要支持的判断，再列出每个面板的证据。描述、关联、因果效应、预测表现分开表达。面板顺序跟随读者理解路径：研究对象或设计 → 主要结果 → 异质性或稳健性，不为凑版式重复数据。

## 数据与图型

| 数据与问题 | 优先图型 | 必须核对 |
|---|---|---|
| 多组连续分布 | 点图、箱线/小提琴叠加原始点 | 样本量、重复测量、离群值规则 |
| 效应及区间 | 森林图、系数图 | 差值/比值、尺度、参考线、区间定义 |
| 时间变化 | 折线、事件研究、分段回归 | 时间间隔、政策时点、对照与置信带 |
| 两变量关系 | 散点、平滑线 | 变换、重叠、拟合方式与外推范围 |
| 多变量结构 | 热图、相关矩阵 | 标准化、聚类距离、缺失、色阶 |

先检查缺失、权重、重复键、极端值和筛选条件；不要从图面外观反推统计模型。保留已有Python/R偏好；已有脚本时在原脚本修改。需要估计模型但尚无分析结果时，先完成分析或明确标为待估计。

## 构图与复现

统一面板字母、术语、字体、线宽和颜色语义。共享坐标轴只在单位与尺度一致时使用。重要结果放在视觉主位，图例靠近对应数据；避免多余边框、3D效果及只靠红绿区分。按实际插入尺寸预览中文、上下标、负号和显著性说明。

保存输入版本、变量映射、筛选规则、模型来源、软件依赖和随机种子（仅在随机过程存在时）。矢量图优先保留文字；PNG/TIFF的尺寸和分辨率按当前投稿要求确定，不能靠增大DPI修复低清原图。

## 可执行入口

已有估计值与区间可使用本库原创脚本：

```bash
python scripts/plot_effects.py effects.csv --out result/effects --scale ratio --label "HR (95% CI)"
```

CSV必须有`label,estimate,lower,upper`；比值尺度要求全部为正。脚本只绘制输入估计，不计算模型或Meta合并；输出SVG/PDF/PNG和输入摘要。Python环境需安装matplotlib，中文标签用`--font`指定已有字体。
