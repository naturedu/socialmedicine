# 🌍 LASI / LASI-DAD · Longitudinal Ageing Study in India

核验日期：2026-10-23。老龄、家庭与健康调查；全国Wave 1、2010试调查及LASI-DAD认知子研究为不同产品。

## 不把发布版当作访谈波次

本机`lasi.csv`331列，变量多为`r1`前缀且无wave列；可支持适当横断面或单次测量研究，不能凭多份A.2/A.3文件生成多期变化。已核对Harmonized A.3中的`r1iwy`、`r1agey`、`r1wtresp`和`r1nwtresp`标签；后两者分别为个人后分层分析及生物标志物权重。

全国Wave1与2010 Pilot分开；LASI-DAD为认知深度子研究，其诊断/测验、知情人及生物资料按独立抽样、访视和权重处理。IIPS官方说明Wave1主要调查期间为2017—2018，Sikkim另有2020—2021采集；因此年份不能统一填2017，疫情前后比较更需谨慎。

### 宽表到分析表

只含一波时保留一人一行，不为了使用面板模型复制多行。若以后取得真实后续访谈，先对照身份键、抽样队列及测量，再生成person-wave。家庭费用放家庭层，个人费用和服务放个人层；同住成员不能形成独立家庭支出记录。

### 量表与公平性

印度的语言、教育、城乡和地区制度差异需体现在测量及解释中。认知测试缺测与识字能力、视听/体能有关时，完整案例子集可能改变目标人群。DAD分类与主调查简短认知分数不能混用；外部预测验证应先确认同一结局定义，区分连续分数、风险分类与经评估的认知诊断。

### 可回答与暂不可回答

单波可研究加权健康分布、服务差异、照护需求与社会资源关联；不能直接识别个体衰退速度、政策前后效应或发病率。若拟用地区政策差异，先确认授权地理信息和处理起始及独立对照；增加交互项不能替代这些条件。

## 🧺 先把数据放进正确的小篮子

建立文件清单：`study / release / module / wave / visit_date / unit / key / source / permission`。文件名中的版本字母、下载年份和访谈波次分开。原始文件只读；另存标准化层和分析层。先输出字段名、标签、值标签、缺失码和连接诊断，再决定变量能否使用。

每个分析变量至少记录：概念、原题、来源变量、适用人群、回顾窗口、单位、跳答路径、特殊码、代理回答、派生公式、可用波次、权重及核验状态。不得只凭中文列名判断值域或方向；`weight`在多份表中是体重。

## 从问题到估计的顺序

1. 写清目标人群、暴露/政策、比较组、结局和时间零点。区分人群患病比例、个体内变化、预测准确性和政策效应。
2. 画样本流：原始入样→年龄/资格→完成访谈→完成测量→连接随访→分析样本。死亡、失访、跳题、拒答、未测量分别记，不统一改成0。
3. 描述研究所需字段在每波的可用性。两波数据最多支持一次变化；多波轨迹需要足够重复观测、可比较测量与合理类数。
4. 按估计目标选择横断面、纵向或特定组件权重；权重不能凭变量名相似借用。失访加权需要可解释的响应模型和正值性诊断。
5. 面板FE估计的是个体内关联；PSM不能消除未测混杂；交错DID还需真实政策起始、前期趋势和有效对照；TTE需对齐资格、分组及随访起点。
6. 保留未加权人数、加权估计与区间。重复测量、家庭和地区依赖按设计处理；缺失值插补与抽样设计的结合需写明方法，避免把插补当作增加独立样本。

## 交付与报告

交付版本清单、变量字典、跨波可用矩阵、连接诊断、样本流、缺失/失访表、模型脚本和执行记录。公共教程仅包含方法与元数据；获准数据留在授权环境。问卷存在某题、当前文件有字段、分析样本有有效观测是三个不同层次。
