# 🌱 CLHLS / CLHLS-HF · 老年健康与家庭追踪

核验日期：2026-10-23。高龄健康与照护研究；2021家庭扩展、存活者问卷、死亡家属问卷和补充样本分别处理。

## 2018—2021：本次文件核对实例

|概念|2018|2021|处理|
|---|---|---|---|
|个人键|id|ID|字符化保留宽度，先查唯一性再一对一；不导出个体值|
|访问日期|yearin/monthin/dayin|year/monthin/dayin|按实际访问组成日期，不以文件名年份替代|
|年龄|trueage|age|核对跨波变化和出生年，不擅自用后波回填基线|
|高血压自报|g15a1|g14a1|本次值标签1是2否；其他码依版本处理|
|慢性肾炎自报|g15t1|g14t1|不能改称实验室CKD或高血压肾病|
|血压两次|g511/g521、g512/g522|g611/g621、g612/g622|先清理特殊码，再按预定规则求均值|

2021 `e64a1—e64a4`标签涉及居家、社区、机构等正式长期照护服务及无服务选项。有效性依赖进入模块的资格和跳题；只看全样本非缺失率会把结构性未问混成数据质量问题。2021 `f61`涉及远程医疗服务使用，其概念比“是否上网”更具体，不与CHARLS上网行为强行同名。

### 连接与死亡竞争

先以主样本框识别可随访对象，再分存活已访、已知死亡、拒访、失联、搬迁和状态未知。2021能匹配者是存活并完成调查的选择样本；仅分析该子集的功能变化会受死亡和失访选择影响。死亡模型必须取得对应本人死亡/随访记录；父母死亡题、未匹配记录都不能替代本人死亡状态。若只有两次访谈，事件只知发生区间，应说明区间删失或离散时间近似。

本次2018/2021核对文件没有发现肌酐、胱抑素C或UACR；这只约束这些具体文件，不能否认CLHLS其他生物样本子项目。计划肾功能研究时先查子项目及可连接性，不能用慢性肾炎自报代替全部肾脏结局。

### 量表与照护需求

逐项列ADL任务、需要帮助程度和评分方向；分开“有困难”“需要人助”“实际得到帮助”和“帮助足够”。认知题保留教育、视听障碍、代理/协助作答标记；不知道与拒答分别处理。研究未满足需求时分母应是有相应需求的人，不是所有高龄参与者。生命表或多状态模型需足够状态转移、死亡链接和时间信息，不能仅凭两个健康总分拟合复杂过程。


## R与Stata：标准化层的最小接口

以下变量名是**分析层约定**，不是原始数据库通用字段。必须先完成题级映射。若没有所需设计变量，先回查官方设计文件，不能任意生成PSU或权重。

```r
# d: id=字符个人键, year=实际访谈年, y=已核对结局, x=预定协变量
stopifnot(!anyNA(d$id), !anyDuplicated(d[c("id", "year")]))
d <- d[order(d$id, d$year), ]
# 纵向条件关联；不自动等于政策因果效应
m <- fixest::feols(y ~ x | id + year, cluster = ~id, data = d)
summary(m)
# 按复杂抽样作描述应另用对应设计与权重，而非仅cluster=id。
```

```stata
* id_s 是字符键，pid 仅作当前数据内面板编码，不输出映射。
assert !missing(id_s, year)
isid id_s year
egen long pid = group(id_s)
xtset pid year
xtreg y x i.year, fe vce(cluster pid)
* 单波数据不运行此面板流程；先选择合适的survey描述/横断面模型。
```

## 🧺 先把数据放进正确的小篮子

建立文件清单：`study / release / module / wave / visit_date / unit / key / source / permission`。文件名中的版本字母、下载年份和访谈波次分开。原始文件只读；另存标准化层和分析层。先输出字段名、标签、值标签、缺失码和连接诊断，再决定变量能否使用。

每个分析变量至少记录：概念、原题、来源变量、适用人群、回顾窗口、单位、跳答路径、特殊码、代理回答、派生公式、可用波次、权重及核验状态。不得只凭中文列名判断值域或方向；`weight`在多份表中是体重。

## 从问题到估计的顺序

1. 写清目标人群、暴露/政策、比较组、结局和时间零点。区分人群患病比例、个体内变化、预测准确性和政策效应。
2. 画样本流：原始入样→年龄/资格→完成访谈→完成测量→连接随访→分析样本。死亡、失访、跳题、拒答、未测量分别记，不统一改成0。
3. 描述研究所需字段在每波的可用性。两波数据最多支持一次变化；多波轨迹需要足够重复观测、可比较测量与合理类数。
4. 按估计目标选择横断面、纵向或特定组件权重；权重不能凭变量名相似借用。失访加权需要可解释的响应模型和正值性诊断。
5. 面板FE估计的是个体内关联；PSM不能消除未测混杂；交错DID还需真实政策起始、前期趋势和有效对照；TTE需对齐资格、分组及随访起点。
6. 保留未加权人数、加权估计与区间。重复测量、家庭和地区依赖按设计处理；缺失值插补与抽样设计的结合需写明方法，避免把插补当作增加独立样本。
