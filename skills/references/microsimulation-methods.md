# 微观模拟：转移、参数、不确定性与验证

实施与审查细节，配合[微观模拟技能](../microsimulation-studio.md)按需阅读。公式和教学参数不能替代疾病证据。

## 1. 模型说明与参数表

模型说明卡回答：为谁比较什么、何时开始、模拟到何时、谁承担成本、输出哪些结局、哪些机制在边界外。

| 字段 | 保留的信息 |
|---|---|
| parameter / transition | 唯一名称、所属状态或转移 |
| value / scale / unit | 率、概率、log-HR、费用率或效用；时间单位与价格年 |
| population / window | 国家、人群、年龄、基线状态、风险期 |
| source / location | DOI/官方链接、表号、页码及估计位置 |
| uncertainty / dependence | SE、区间、分布、协方差或联合抽样方式 |
| transform / assumption | 原始估计到模型输入的转换与外推依据 |
| role / status | 估计、校准或固定；核验状态；是否用于外部验证 |

本地数据只在授权环境处理。发布技能不意味着可以发布受访者记录、数据字典或私人方案。

## 2. 风险单位与竞争事件

在区间内恒定单一风险率假设成立时，率r转换为周期Δt内概率：`p = 1 - exp(-r * Δt)`。已知长度Δt₀内单一事件概率p₀时，才可用 `r = -log(1-p₀)/Δt₀` 推导另一风险窗。

同一状态有K个互斥竞争事件、原因别风险率在该周期恒定时：总率 `R = Σ r_k`，不转移概率 `exp(-R * Δt)`；第k种首次事件概率 `r_k/R * (1-exp(-R * Δt))`；R为零则全部留在原状态。不能把各事件独立转换后的概率直接相加。

这描述一个周期内的首次事件。教学代码每周期只执行一次转移，不模拟发病后同周期死亡等后续事件。高转移率、急性事件或次序重要时需缩短周期、使用子周期/隧道状态或连续时间/DES，并比较结果。

HR在对应风险率上作用需保证基线风险、人群和比例风险假设兼容；HR不等于概率比，OR也不能直接当RR或HR。多状态系统跨波概率逐项取对数不能恢复完整生成矩阵；应拟合适当多状态模型，或核验矩阵变换的可嵌入性与临床含义。

## 3. 属性、历史与更新次序

保存周期初状态与属性，由此计算风险；抽样后统一更新，避免新患病者在同一循环再次转移。另存病程、既往事件次数、既往治疗和累计暴露。

若同周期允许多个事件，定义事件时间、先后及条件依赖；不能由代码排列偶然决定。死亡后停止产生疾病事件和持续费用，死亡相关一次性费用按定义单独累计。

年龄按周期长度增加；日历年、达到年龄、出生队列不能混用。开放人口另需进入、移出、人口权重与进入时健康状态规则。全国病例数需全国人口分母，不能把模拟人数当真实人数。

## 4. 成本、效用与增量评价

状态率乘处于该状态的时间；事件费用按事件累计。年率输入须乘周期年数。教学脚本用周期初末效用/成本率的均值近似累计，在周期中点贴现，构成半周期近似；这不能修复粗周期的结构错误。

分别记录健康/成本贴现率、时间零点、是否贴现和价格年。核对效用是否含年龄损害、合并症组合及照护者影响。非正式照护、生产力损失和效用损害避免重复计入。

至少报告ΔC、ΔE和各支付意愿λ下的 `INMB = λ * ΔE - ΔC`。保留适当分位数及分层结果；多策略比较需检查简单/扩展支配，再构建成本效果前沿。

## 5. 不确定性与随机数

| 类型 | 怎么检查 | 解释边界 |
|---|---|---|
| 个体事件随机性/一阶模拟误差 | 固定人群和参数，增加N、更换独立随机流，比较增量及MCSE | 不是参数置信区间 |
| 参数不确定性/二阶PSA | 按联合参数分布抽样，每组参数比较同一人群及策略 | 不能覆盖全部结构和外推假设 |
| 结构、实施与外推情景 | 改变状态、风险时间函数、疗效持续、依从和容量 | 不能仅增加PSA次数替代 |

共同随机数对应同一人的同一周期和事件类型。死亡者也保留随机流索引，避免退出造成策略间错位。可预生成矩阵或使用按人/事件定义的随机流；只设置相同种子未必足够。共同随机数常能降低增量噪声，但不是所有结构都保证改善。

回归参数按系数及协方差联合抽样；beta/gamma/lognormal分布需匹配支持集和估计含义。bootstrap也需保留原抽样/聚类结构。

R教学示例固定合成人群，以独立事件流重复比较：`mcse_single_run`为不同运行增量均值的标准差，估计一次运行的误差规模；`mcse_average`除以重复次数平方根，是多次平均值的MCSE。两者条件于固定基线和参数，不含基线估计或参数不确定性。

教学PSA只随机化虚构的起病HR和项目年成本，固定同一事件矩阵以降低噪声；不覆盖风险方程、成本效用、相关性等真实参数空间。CEAC仅示范计算，应先检查人数收敛和残余一阶噪声。

## 6. 校准与验证

| 层次 | 检查 | 报告 |
|---|---|---|
| 程序验证 | 概率合法、人数守恒、死亡吸收、零风险、恒等策略、种子重现、时间费用单位 | 实际测试及结果 |
| 内部重现 | 拟合/校准样本发病、生存、严重度和照护分布 | 已使用数据与目标 |
| 外部验证 | 未用于拟合/校准的时期、地区、队列或结局，匹配定义和分母 | 预测对观测、误差和迁移限制 |
| 结构审查 | 机制、病史、竞争事件、周期长度、开放人口 | 判断依据与情景差异 |
| 决策稳健性 | 人数/随机流收敛、PSA、阈值和结构情景 | 结论改变条件及证据缺口 |

校准说明自由参数、目标与目标误差/权重、目标函数、搜索算法、边界及可辨识性。保留多个可接受组合可揭示识别限制；不能以“患病率接近文献”代替全部验证。

## 7. 执行状态

2026-10-24在Windows、R 4.6.1、base R环境实际运行教学示例和独立不变量检查，涵盖竞争概率、人数守恒、死亡吸收、恒等策略、零风险解析累计、无效输入及种子重现。仅证明本教学实现的已检查行为，不代表真实疾病参数、真实数据或引用模型已复现。

Stata `.do` 尚未在Stata执行；包含相同四状态机制、共同随机数和成本/QALY累计，没有实现R的完整重复模拟和PSA接口。两种软件随机数不同，不要求单次轨迹一致。

## 8. 从论文到自己的模型

先用[来源对照](microsimulation-sources.md)选择模型家族。结构可借鉴，系数、效用及照护成本需本地适用性依据。逐项建立“原文估计→转换→模型输入”链条；缺少系数、协方差、自然史或外部目标时列为证据缺口。没有原代码及完整参数时称方法借鉴或独立教学实现，不称完整复现。
