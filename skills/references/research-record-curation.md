# 研究记录压缩与方法沉淀

用于用户要求整理多个项目、压缩操作记录或把经验纳入技能库时。整理对象是项目状态和可复用知识；原始数据、稿件和账户记录分别管理。

## 一份可接续的项目摘要

每个项目记录：目标、当前阶段、权威成果路径、关键决定及其依据、已经执行的验证、尚未解决的问题、下一步。保留结论的证据位置；删除摘要中的重复进度播报、无效尝试全文与过时计划。未完成、失败、被中断和未加载是不同状态，不能统一写成“已完成”。

先说明清点范围：会话列表、可访问的历史索引、读取过的近期轮次、扫描的目录深度及排除项。标题索引不等于读过全文；缺少分页或历史记录时明确边界，不声称整理了整个账号所有历史。

## 留存与清理

| 内容 | 处理方式 |
|---|---|
| 最终成果、必要源文件、证据表、复现依赖、未完成事项 | 保留，指向当前权威版本 |
| 旧版导出、无用预览、字体或布局测试产物 | 核对引用后压缩归档，保存原路径、大小与哈希 |
| 同名或同哈希文件 | 仅标候选；可能是独立项目所需副本，不能直接删除 |
| 论文、个人申请材料、受限数据、数据库、登录与账户配置 | 不纳入公共技能库，不因清理聊天而改动 |
| 已完成的一次性临时会话 | 在用户授权的整理范围内可归档；归档与永久删除分开说明 |

清理前核对文件是否被构建脚本、数据流程或当前成果引用。先验证归档可读和内容哈希，再处理原文件；保留恢复映射。不要把整个扫描目录的容量当作可释放空间，也不要把压缩前大小当作实际节省量。

## 从项目经验提炼技能

只写影响下一次决策的内容：输入条件、方法选择、关键检查、容易混淆的边界和交付结构。先搜索现有技能，已有内容补链接或补一个缺口，不把每次任务复制成新技能。

公共同步使用新增文件清单。原始会话、私人联系方式、未发表正文、具体未公开研究构思、账户信息和本机路径留在本地。代码提炼后改为可配置路径和示例数据；只有实际运行过的部分标为已验证。

更新技能前检查当前仓库版本与本机安装版差异；只同步本次修改，避免旧副本覆盖其他项目的新内容。交付报告分别说明本地整理、文件归档、会话归档、技能安装与远端同步的实际状态。
