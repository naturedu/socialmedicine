# 进阶因果与评价方法

原有 54 条方法和 11 份专题手册保留。以下补充用于区分研究问题与识别策略，不把复杂方法当作有效因果识别的保证。

| 方法 | 数据与估计目标 | 必须核对 | 推荐原始方法入口 |
|---|---|---|---|
| 目标试验模拟 TTE | 明确人群、策略、分配、零时点、随访、结局、因果对比与分析 | 入组/策略/随访时间对齐；不朽时间偏倚；按方案效果的时变混杂 | [Hernán & Robins, 2016](https://doi.org/10.1093/aje/kwv254) |
| 双重机器学习 DML | 用交叉拟合估计干扰参数，围绕明确的低维因果参数 | 可识别性、重叠、折划分及组间泄漏；不能消除未测混杂 | [Chernozhukov et al., 2018](https://doi.org/10.1111/ectj.12097) |
| 合成控制 SCM | 用未受处理单位构建处理前匹配的反事实 | 供体污染、拟合、单元数量、安慰剂与外推 | [Abadie et al., 2010](https://doi.org/10.1198/jasa.2009.ap08746) |
| 合成双重差分 SDID | 结合单位和时间权重估计面板处理效应 | 平衡面板、共同处理时点、权重稳定性与推断 | [Arkhangelsky et al., 2021](https://doi.org/10.1257/aer.20190159) |
| 交错 DID | 按首次受处理时期估计组别时间 ATT | 异质效应、有效对照、预期效应与前趋势检验功效 | [Callaway & Sant’Anna, 2021](https://doi.org/10.1016/j.jeconom.2020.12.001) |
| 竞争风险 | 明确目标事件与竞争事件；估计 CIF 或相应风险函数 | 1−KM 不能替代存在竞争事件时的 CIF；区分原因特异与亚分布风险 | [Fine & Gray, 1999](https://doi.org/10.1080/01621459.1999.10474144) |

## 代码使用边界

代码库集中原有 Stata/R 片段，保留来源手册和行号。它们依赖前文的数据结构、变量和安装步骤，不宜将任意单块当作完整脚本。混合 Stata/R 片段已单独标注。运行前先选软件，再逐项配置数据、聚类层级、时间结构与 estimand。

没有 Stata/R 执行环境时，只能报告“模板整理/静态检查”，不能写“运行通过”。已有 Python 耦合计算脚本附小型已知答案测试，不以此证明所有方法代码可靠。

## 对原手册的补充校准

- 个体匹配和频数匹配的病例对照研究不必使用相同回归方式。
- 随机化使协变量在随机化分布上平衡，不保证一次小样本恰好平衡。
- 未拒绝平行趋势假设不等于证明平行趋势成立。
- 传统双向固定效应在交错处理且效应异质时可能不能代表期望的 ATT。
- `csdid` / `csdid_plot` 是社区命令；Stata 官方异质性 DID 命令另有 `hdidregress` / `xthdidregress`。
- 机器学习预测准确度、SHAP 解释与因果效应是不同对象。
- 主题模型与文献网络用于探索证据结构，不生成临床或政策结论。
