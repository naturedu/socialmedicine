# 主题演变、作者机构与文献网络

## 计数口径

将互斥主主题、多标签关键词和阅读分组分开存储。图题写清分母、计数单位与年份口径。不同长度的分期先比较期内比例并列 n；最新不完整年份单独标注，不能据此断言研究衰退或增长。

主题词可从标题、作者关键词、摘要分别提取；记录词表、停用词、合并词和词边界。英文 mental 不能误命中 experimental/environmental。自动聚类标签由人工检查代表文献，并保留不确定项。

使用LLM时保存模型、提示词、输入字段和版本；独立人工参照与模型再次复核分开，未命中记录也需抽样检查才能评估漏检。多标签条形图可重复计数；桑基图采用每项目 1/k 主题分数计数时应核对流量守恒。基金项目的具体覆盖、地理与推断边界见[科研资助分析](../funding-landscape-skill.md)。

## 作者与机构

作者名缩写不是身份唯一标识。合并前核对 ORCID、单位与论文上下文；学者介绍基于公开履历和多篇已核验成果，选择样本不代表完整职业轨迹。时间先后不证明研究之间有因果继承。

机构保留原文、规范名、ROR/OpenAlex ID 和层级；学校、医院、学院、实验室不混为同一层级。全计数与分数计数分别报告，不以少量精选机构代表全部合作网络。

中国机构参与与中国研究场景分开编码；可以重叠，不简单相加。不能依据姓名推断国籍。香港、澳门、台湾及跨国研究的分析分类需说明，不能暗中改变统计口径。

## 网络

文献耦合指两篇论文共享参考文献；共被引指两篇文献被后续论文一起引用。共同作者属于另一种网络。

基金题名中的词语共现不属于文献耦合；没有参考文献数据时应使用“关键词共现”或“主题关联”。分期地图只使用证据支持的定位粒度，圆面积与数量成比例；机构所在地不能替代研究受益地区。

令二值参考文献矩阵 B 的行是论文、列是规范 DOI。共同参考数为 B Bᵀ，余弦耦合为共享数 / sqrt(各自参考 DOI 数乘积)。没有参考数据不是没有共同知识基础，应标记缺失并报告参考文献覆盖率。

先输出节点、边和阈值，再选 Louvain/Leiden 等算法。记录随机种子、分辨率、最小边权及孤立点；比较若干合理阈值，社区不稳定时不用唯一群组讲强故事。网络强度不代表论文质量或政策效果。

## 优先图形

1. 检索筛选流图：纳入、排除及待核之和应自洽。
2. 年份 × 主题热力图：计数与比例可切换，有分母。
3. 机构点图或排序图：明确全计数/分数计数，数量不是排名评价。
4. 作者路径：标论文年份、方法及证据，禁止补造职业经历。
5. 耦合网络：与边表和阈值说明一起交付。

图像美化不能改变轴、数据、置信区间和样本量。小屏优先减少同时呈现的信息，不用极小字体掩盖信息过载。
