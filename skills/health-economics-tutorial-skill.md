### 第 1 步：提出研究问题与评价类型选择

**方法**：

- **四种评价类型**：
  - **CMA（最小成本分析）**：结局已被证明（或有充分证据）等效，只比较成本。前提严格，实践中极少能完全满足，慎用。
  - **CEA（成本-效果分析）**：效果用自然单位（血压 mmHg、避免的发作次数、生命年等），适合结局单一的研究；不同自然单位之间不可直接比较。
  - **CUA（成本-效用分析）**：CEA 的特例，效果用 QALY / DALY 等偏好加权指标，可跨疾病比较，是药品经济学评价与医保准入最常用的类型。
  - **CBA（成本-效益分析）**：成本与效果都货币化（支付意愿 WTP），用净货币收益（NMB）或效益-成本比判断；当需要与教育、环境等非健康领域比较时使用。
- **选择决策树（按顺序判断）**：① 结局是否等效？是 → CMA；② 是否需要跨部门 / 跨领域比较？是 → CBA；③ 效果能否且需要转换为偏好加权指标（QALY）？是 → CUA；④ 其余情况 → CEA。国内指南默认推荐 CEA/CUA。
- **PICO-T 研究问题模板**（在 P 中，与 C 相比，I 在 T 内对 O 的增量成本与效果如何）：

```
P（人群）：某慢性病患者（示例：2 型糖尿病、病程 ≥ 5 年、无严重并发症）
I（干预）：新综合管理方案
C（对照）：常规治疗
O（结局）：QALY（及并发症发生率等自然单位结局）
T（时间范围）：10 年
研究问题：在 P 中，与 C 相比，I 在 T 年内对 O 产生的增量成本与增量效果如何？
           ICER 是否低于支付意愿阈值 λ？
```

### 第 2 步：研究视角与时间范围

**方法**：

- **研究视角决定纳入哪些成本**：
  - **医保支付方视角**：只纳入医保基金支付的项目（报销的药品、检查、住院等）。
  - **卫生体系视角**：医保基金 + 政府财政投入 + 患者自付医疗费用等所有卫生体系内资源。
  - **社会视角**：卫生体系成本 + 患者与家庭的直接非医疗成本（交通、陪护、食宿）+ 生产力损失（间接成本）。信息最全、最接近全社会的真实代价，但数据要求最高；《中国药物经济学评价指南（2020）》建议以全社会或卫生体系视角为主，至少明确报告视角。
- **时间范围**：必须**足够长以覆盖干预引起的全部重要成本与效果差异**——慢性病常需 10 年以上乃至终身，疫苗与急性感染可短至数月到数年。时间范围过短会系统性遗漏后期收益（尤其预防、筛查类「成本前置、收益后置」的干预），此时贴现率的影响也更大。本算例取 10 年。
- **提示**：视角、时间范围在研究方案中先定，并在结果表中注明；换视角或换时间范围必须重新测算，不能事后拼凑。

### 第 3 步：成本测算

**方法**：

- **三类成本**：
  - **直接医疗成本**：药品、检查、手术、住院、康复等卫生资源消耗，按卫生服务量 × 单位价格估值。
  - **直接非医疗成本**：患者与家庭为就医发生的交通、食宿、陪护等支出。
  - **间接成本（生产力损失）**：因病休工或早亡损失的生产时间。**人力资本法（HCA）**按工资（或人均 GDP）乘以损失时间；**摩擦成本法（FCM）**只计入「岗位空缺到恢复生产」的摩擦期（通常 3–6 个月），更保守。指南 2020 建议社会视角下报告生产力损失，二法择一并说明理由。
- **成本测算三步**：① **识别**——列出与干预相关的资源条目（依据指南、临床路径、专家咨询）；② **测量**——记录资源消耗数量（人次、天数、剂量）；③ **估值**——数量 × 单位成本。
- **中国情境提示**：单位成本来源常用——各省市医疗服务项目价格规范、国家/省级药品耗材集中采购中标价、《国家基本医疗保险药品目录》报销规则；**必须注明价格年份与地区**，跨年价格用 CPI 或医疗 CPI 调整到基年（如 2026 年）。
- **统计**：成本数据通常右偏，除正态近似 CI 外建议报告 bootstrap CI；组间比较看成本差而非只看各组均值。

```stata
* bootstrap：两组成本之差的 95% 百分位区间与偏差校正（BC）区间

program define diff_cost, rclass
    quietly summarize cost if group == 0
    local m0 = r(mean)
    quietly summarize cost if group == 1

```

```r
cost0 <- c(6000, 5500, 6800, 5900, 6200, 6100, 5700, 6400, 5800, 6000)
cost1 <- c(9000, 8800, 9500, 9200, 8900, 9600, 9100, 9300, 9000, 9400)
c(mean0 = mean(cost0), mean1 = mean(cost1))
t.test(cost0)$conf.int          # 对照组 95% CI（正态近似）
t.test(cost1)$conf.int          # 干预组 95% CI

# bootstrap：两组成本之差的 95% 百分位 CI
library(boot)
d <- data.frame(cost = c(cost0, cost1), group = rep(c(0, 1), each = 10))
diff_mean <- function(data, i) {
  g <- data[i, ]
  mean(g$cost[g$group == 1]) - mean(g$cost[g$group == 0])
}
set.seed(2026)
b <- boot(d, diff_mean, R = 1000)
boot.ci(b, type = "perc")       # 差值点估计 ≈ 9180 - 6040 = 3140 元
```

### 第 4 步：效果与效用指标

**方法**：

- **QALY（质量调整生命年）** = 生存时间 × 健康效用权重（0 = 死亡，1 = 完全健康；可为负，表示比死亡更差的健康状态）。多状态时逐段累加：QALY = Σ 效用_i × 时长_i。
- **DALY（伤残调整生命年）** = YLL（早亡损失生命年）+ YLD（伤残状态生存年 × 伤残权重）。QALY 与 DALY 概念互补，数值不可直接互换，选一个并说明理由。
- **效用值的测量**：
  - 直接法：标准博弈（SG）、时间权衡（TTO），测量负担重；
  - 间接法（多属性效用量表）：**EQ-5D** 最常用——EQ-5D-3L 用中国人群 TTO 积分体系（Liu 等，2014）；EQ-5D-5L 用已发表的中国积分体系（存在多个版本，**报告时必须注明所用体系**）；
  - 陈述性偏好法：**DCE 也可测量偏好权重与支付意愿**，作为效用值的补充或替代——设计、估计与 WTP 换算见《DCE 设计助手》skill。
- **效果证据来源**：RCT、系统评价/Meta 分析；相对效果结合基线风险外推长期结局时，见《Markov 模型助手》skill。
- 本算例：对照年效用 0.70、干预 0.78，持续 10 年（未贴现）。

**代码**：


### 第 5 步：贴现

**方法**：

- **成本与效果用同一贴现率**贴现到基年：PV = C_t / (1 + r)^t（t 为相对基年的年数）。理论上有主张对健康效果用更低贴现率的讨论，但实践与指南要求同一贴现率（可另作敏感性分析分别检验）。
- **《中国药物经济学评价指南（2020）》**：贴现率建议 **5%**，敏感性分析取 **0–8%**。时间范围超过 1 年必须贴现；基年（如 2026 年）与价格年份须注明。
- **重要提示**：若各年增量成本与增量效果恒定，分子分母同乘同一贴现因子，ICER 不随贴现率改变（本算例即如此）；当成本与效果**时间分布不同**（成本前置、收益后置的预防与筛查类干预）时，贴现率会显著改变 ICER——这正是必须做贴现率敏感性分析的原因。
- 本算例：10 年、5% 的年金贴现因子 ≈ 7.7217；贴现后 ΔC = 4,000 × 7.7217 ≈ 30,886.9 元，ΔE = 0.08 × 7.7217 ≈ 0.6177 QALY。

**代码**：

```stata
* Stata：贴现因子与 10 年年金贴现因子（r = 5%）
scalar r = 0.05
scalar df = 0
forvalues t = 1/10 {
    scalar df = df + 1 / (1 + r)^`t'
}
display "10 年、5% 的年金贴现因子 = " %9.4f df      // 7.7217

* 贴现后的增量成本与增量效果
scalar dC = (12000 - 8000) * df
scalar dE = (0.78 - 0.70) * df
display "贴现后 ΔC = " %9.2f dC                      // 30886.93 元
display "贴现后 ΔE = " %9.4f dE                      // 0.6177 QALY

* 贴现率敏感性（0–8%）
foreach rr in 0 0.03 0.05 0.08 {
    scalar df = 0
    forvalues t = 1/10 {
        scalar df = df + 1 / (1 + `rr')^`t'
    }
    display "r = " `rr' "：10 年年金贴现因子 = " %9.4f df
}
```

```r
# R：贴现与贴现率敏感性
r <- 0.05; t <- 1:10
disc <- 1 / (1 + r)^t
sum(disc)                                   # 7.7217（10 年、5% 年金贴现因子）
dC <- (12000 - 8000) * sum(disc)            # 30886.9（贴现后增量成本，元）
dE <- (0.78 - 0.70) * sum(disc)             # 0.6177（贴现后增量 QALY）

# 贴现率敏感性（0–8%）
sapply(c(0, 0.03, 0.05, 0.08), function(rr) sum(1 / (1 + rr)^(1:10)))
# 本算例年增量恒定 → 贴现率不改变 ICER（= 4000 / 0.08 = 50000）；
# 成本与效果时间分布不同时，ICER 会随贴现率变化（见第 7 步）
```

### 第 6 步：增量分析与 ICER

**方法**：

- **只报增量，不报平均**：ICER = ΔC / ΔE = (C1 − C0) / (E1 − E0)。平均成本-效果比（ACER）会误导决策，禁止作为主要结论。
- **成本-效果平面四象限解读**：
  - 东北（ΔC > 0，ΔE > 0）：更贵更有效 → 与阈值 λ 比较，ICER < λ 则有成本-效果；
  - 东南（ΔC < 0，ΔE > 0）：更便宜更有效 → **优势（dominant）**，直接推荐；
  - 西北（ΔC > 0，ΔE < 0）：更贵更差 → **劣势（dominated）**，直接拒绝；
  - 西南（ΔC < 0，ΔE < 0）：更便宜更差 → 权衡：节省的成本是否值得损失的效果（用 ICER 或净收益判断）。
- **与阈值比较**：支付意愿阈值 λ 以 **1–3 倍人均 GDP 为参考区间**（国内常用口径；《中国药物经济学评价指南（2020）》以 1 倍人均 GDP 为主要参考，应用时以最新版指南与决策机构口径为准，并对 λ 做敏感性分析）。本算例取人均 GDP = 100,000 元（示例，以官方公布为准），λ = 100,000–300,000 元/QALY。
- 本算例：ICER = 30,886.9 / 0.6177 ≈ **50,003 元/QALY** < 100,000 → 具有成本-效果。净货币收益 NB(λ) = λ·ΔE − ΔC = 100,000 × 0.6177 − 30,886.9 ≈ 30,887 元 > 0，结论一致。

**代码**：

```stata
* Stata：ICER、净收益与四象限判断
scalar dC = 30886.9
scalar dE = 0.6177
scalar lambda = 100000
display "ICER = " %9.1f dC / dE                    // ≈ 50003 元/QALY
display "NB(λ=100000) = " %9.1f lambda * dE - dC   // ≈ 30887 元

if dC > 0 & dE > 0 {
    display "东北象限：更贵更有效 → 比较 ICER 与 λ"
    display cond(dC/dE < lambda, "ICER < λ → 具有成本-效果", "ICER ≥ λ → 不具有成本-效果")
}
else if dC < 0 & dE > 0 {
    display "东南象限：更便宜更有效 → 优势策略，直接推荐"
}
else if dC > 0 & dE < 0 {
    display "西北象限：更贵更差 → 劣势策略，拒绝"
}
else {
    display "西南象限：更便宜更差 → 权衡节省与效果损失"
}
```

```r
# R：ICER、净收益与四象限判断
dC <- 30886.9; dE <- 0.6177
lambda <- 100000
ICER <- dC / dE                                    # ≈ 50003 元/QALY
NB   <- lambda * dE - dC                            # ≈ 30887 元（净货币收益）
quadrant <- if (dC > 0 && dE > 0) "NE：更贵更有效（与 λ 比较）" else
            if (dC < 0 && dE > 0) "SE：更便宜更有效（优势）" else
            if (dC > 0 && dE < 0) "NW：更贵更差（劣势）" else
            "SW：更便宜更差（权衡）"
verdict <- ifelse(ICER < lambda, "ICER < λ，具有成本-效果", "ICER ≥ λ，不具有成本-效果")
list(ICER = ICER, NB = NB, quadrant = quadrant, verdict = verdict)
```

### 第 7 步：不确定性分析

**方法**：

- **单因素敏感性分析（one-way / tornado）**：每次只变动一个参数（如 ±20%、极值、95% CI 上下界），其余固定，按对 ICER 的影响大小排序，画 tornado 图；影响最大的参数是结论稳健性的关键。
- **多因素 / 场景分析**：同时变动多个参数的极端组合（如最优情形、最差情形）。
- **概率敏感性分析（PSA）**：所有参数同时从各自分布抽样——成本常取 gamma / lognormal（保证非负），概率取 beta，相对风险取 lognormal，效用取 beta——蒙特卡洛迭代 ≥ 1000 次，输出成本-效果平面散点图与成本-效果可接受曲线（CEAC）。从参数层面抽样的完整实现（含 Markov 状态转移与参数相关结构）见《Markov 模型助手》skill；本步骤 R 代码给「直接从 ΔC、ΔE 分布抽样」的示意版本。
- 本算例：ΔC ~ N(30,886.9, 3,200²)、ΔE ~ N(0.6177, 0.05²)（示意；正式研究应从参数层面抽样）。tornado 参数：ΔE ±20%、ΔC ±20%、干预年效用 0.73/0.83。

**代码**：

```stata
* Stata：单因素敏感性分析（基线 ICER ≈ 50003 元/QALY）
scalar dC = 30886.9
scalar dE = 0.6177
display "基线 ICER            = " %9.1f dC / dE
display "ΔE +20% 的 ICER      = " %9.1f dC / (dE * 1.2)
display "ΔE −20% 的 ICER      = " %9.1f dC / (dE * 0.8)
display "ΔC +20% 的 ICER      = " %9.1f (dC * 1.2) / dE
display "ΔC −20% 的 ICER      = " %9.1f (dC * 0.8) / dE

* 干预组年效用取 0.73 / 0.83（其余不变；贴现后 ΔE = Δu × 7.7217）
display "干预效用 0.73 → ICER = " %9.1f dC / (0.03 * 7.7217)
display "干预效用 0.83 → ICER = " %9.1f dC / (0.13 * 7.7217)
* 解读：ICER 范围约 30769–133333 元/QALY，跨过 λ = 100000 →
* 结论对效用参数敏感，报告中须突出说明
```

```r
# R：概率敏感性分析（PSA）示意——直接从 ΔC、ΔE 的分布抽样；
# 正式研究应从参数层面抽样（成本 gamma、概率 beta、RR lognormal），
# 完整实现见《Markov 模型助手》skill。
set.seed(2026)
n <- 1000
dC <- rnorm(n, mean = 30886.9, sd = 3200)     # 增量成本（元）
dE <- rnorm(n, mean = 0.6177, sd = 0.05)      # 增量 QALY

# 成本-效果平面散点图（λ = 100000 元/QALY 的斜率线）
plot(dE, dC, xlab = "ΔE（QALY）", ylab = "ΔC（元）", pch = 20,
     cex = 0.5, col = rgb(0, 0, 0, 0.3), main = "PSA 成本-效果平面散点图")
abline(h = 0, v = 0, lty = 2)
abline(a = 0, b = 100000, col = "red")        # 斜率 = λ

# 各象限模拟点占比
quad <- ifelse(dE > 0, ifelse(dC > 0, "NE", "SE"),
               ifelse(dC > 0, "NW", "SW"))
table(quad) / n

# 成本-效果可接受曲线（CEAC）：P(NMB(λ) > 0)
lam  <- seq(0, 300000, by = 5000)
ceac <- sapply(lam, function(x) mean(x * dE - dC > 0))
plot(lam, ceac, type = "l", xlab = "支付意愿阈值 λ（元/QALY）",
     ylab = "具有成本-效果的概率", ylim = c(0, 1))
abline(h = 0.5, lty = 3)
```

## 常见错误清单

- [ ] 成本与效果使用**不同的贴现率**（必须同一贴现率，可另做敏感性分析分别检验）
- [ ] 用**平均成本-效果比（ACER）**代替增量比（ICER）
- [ ] 把**统计显著当作经济显著**（P < 0.05 ≠ ICER < λ）
- [ ] **忘记报告不确定性**（无单因素敏感性、无 PSA，直接下结论）
- [ ] **阈值误用**（套用别国或过期的阈值；把 1–3 倍人均 GDP 当绝对标准而不对 λ 做敏感性分析）
- [ ] 时间范围过短，漏掉后期成本/效果（预防、筛查类干预尤甚）
- [ ] 成本与效果**基年 / 价格年份不一致**，或未按 CPI 调整
- [ ] 效用值套用**外国人群的积分体系**直接用于中国人群（EQ-5D 应使用中国积分体系并注明版本）
- [ ] 用中间结局（血压、生化指标）代替最终结局（死亡、QALY）
- [ ] 未说明研究视角，却混用不同视角下的成本条目
- [ ] 成本数据明显右偏仍只用正态近似，不报告 bootstrap CI
- [ ] PSA 参数分布选择无依据（如成本用对称正态导致抽样出现负成本）
- [ ] 未按 CHEERS 2022 逐条自查，方法细节缺失导致不可复现
