# 第四步：以证据为中心的文字润色

在科学问题、结构、主要结果和图表基本稳定后读取本文件。用户说“去人味”“去 AI 味”时，结合上下文处理为减少模板化表达、空话和项目操作痕迹，让学术语言自然、具体、便于判断。

本步骤不判断作者身份，不承诺通过检测器，也不为了显得像人写作而故意加错字、改乱逻辑或抹去证据限制。

## 1. 确定改写范围

- 找到用户确认的文稿、图表、参考文献库和分析版本；不要把较新的零散片段自动视为全稿基准。
- 只做语言润色时保持研究问题、设计、样本、数字、结论方向和引文支持关系。
- 发现实质错误时单独标记其位置与依据；在授权范围内纠正并记录，不能把统计修订藏在“润色”里。
- 单纯补充背景与讨论文献，不改变系统综述的纳入范围、检索日期和 PRISMA 计数。
- 同一文稿使用一致的语言和期刊语域。中文解释稿与英文投稿稿分开，避免把工作说明混进正文。
- 按当前任务读取相应章节，不要求每次从头重写全文。

## 2. 先建立需要保留的事实清单

从确认版本提取或检查以下内容，规模随任务大小调整：

| 对象 | 润色时不应漂移的内容 |
|---|---|
| 研究问题 | 对象、情境、暴露/干预、比较、结局及时间窗 |
| 方法 | 研究设计、数据来源、变量定义、分析集、模型及处理步骤 |
| 结果 | 样本量、分母、效应量、置信区间、P 值、缺失与敏感性结果 |
| 解释 | 关联/预测/因果层级、适用人群、探索性或验证性地位 |
| 引用 | 每条文献支持的具体论断、年份、作者及编号 |
| 声明 | 作者、机构、伦理、注册、资助、利益冲突和数据可用性 |

短段落可直接核对，不必另建复杂台账。全文修订时保留精简的术语表和关键数字核对表。

## 3. 用科学问题组织段落

每段应有能被概括的一句话功能：说明问题、建立缺口、交代方法、报告结果或解释意义。段落之间通过问题与证据推进，而非连续堆叠连接词。

- **Introduction：** 从具体临床、管理或政策问题进入，说明已有研究已回答什么、尚缺哪项证据，再落到本研究目标。
- **Methods：** 让读者知道对象怎么进入、变量怎么定义、数据怎么处理、分析为什么适用及如何执行。
- **Results：** 先报告与研究问题直接相关的主要结果，再补比较、异质性和敏感性；避免逐格复述所有表格。
- **Discussion：** 从主要发现开始，解释与既有证据一致或不同之处，给出有根据的机制与情境解释，再说明局限和可支持的应用。
- **Conclusion：** 直接回答研究问题；结论强度与设计、结果及不确定性一致，不突然扩大到未研究的群体或制度。

“具体”意味着交代对象、行动、条件与证据，不意味着给每句话加修饰词或把段落拉长。

## 4. 优先处理五类表达

| 问题 | 修改方式 | 保留边界 |
|---|---|---|
| 空泛重要性 | 用研究情境、已核实负担或决策难点说明意义 | 没有来源就不补宏大数字或“首个”结论 |
| 模板化贡献 | 写清本研究增加了哪项证据、改变了什么判断 | 不把常规方法包装为突破 |
| 冗余防御语 | 删除不增加信息的“需要强调的是”“谨慎解读”等套话 | 保留会影响解释的偏倚、不确定性与外推边界 |
| 项目操作痕迹 | 删除“本轮补充”“按要求改为”“经模型生成”等过程叙述 | 方法中应报告的真实研究过程与 AI 使用披露按要求保留 |
| 名词堆叠与长句 | 用明确主语和动词拆开因果链、并列项与条件 | 不改变术语和专业含义，不为口语化牺牲准确性 |

不要机械禁用所有常见词。词语是否保留，取决于它在当前句子中是否提供信息。

## 5. 让表述直接，而不夸大

- 有结果就写结果，不用“具有十分重要的意义”代替数据或解释。
- 没有因果识别支持时，避免把“相关”“差异”升级成“导致”“改善”或“有效”。
- 阴性或不精确结果同样清楚报告；不通过删亚组、改结局名称或只强调显著结果制造更强叙事。
- 不显著不等于没有作用，也不等于两组等效；按估计值和区间说明证据支持程度。
- 比较优势须有同条件比较依据；没有外部验证时不能仅凭内部性能声称普遍适用。
- 区分统计显著性、效应大小和临床/政策意义；三者不能用一个“显著改善”代替。
- 机制解释标明证据来源；本研究没有检验的机制，可以提出合理解释，但不能写成已证实路径。
- 研究局限写具体来源及影响，不用一串通用限制，也不把不确定性全部删掉来获得“定论”。

## 6. 改写示例（仅示意，不含真实研究结果）

**空泛表达：** “本研究填补了该领域的重要空白，为实践提供了全新的重要参考。”

**更具体：** “本研究比较了不同服务情境下的使用情况，并评估了与使用差异相关的因素。”

是否可以使用后一句，取决于研究是否真正完成了这些比较和分析。

**操作痕迹：** “根据审稿人的要求，我们在本轮重新加入了敏感性分析。”

**正文写法：** 直接说明所做的敏感性分析及其结果；“根据审稿意见新增”留在回复信和改动记录中。

**过度定论：** “结果证实该措施没有任何影响。”

**证据一致写法：** 报告估计值与区间，并说明能否排除具有实际意义的影响；不凭 P 值选择固定套句。

## 7. 引文与术语检查

- 保留引用所支持的最小论断；句子合并后重新检查每项论断是否仍有对应文献。
- 新加文献先核验题名、年份、期刊、DOI和正文支持；只看摘要时写清核验范围。
- 需要最新证据时实际检索，不通过修改年份制造“最新文献”。
- 引文移动、删除或新增后同步参考文献编号；正文、表注和补充材料采用相同规则。
- 统一结局、暴露、分组和时间窗的名称；首次定义缩写后保持一致。
- 英文润色保留专业术语的精确含义；中文说明避免未解释的英文缩写和逐词直译。

## 8. 交付与复核

1. 提供完整清稿；用户要求标红或逐句修订时，另给对应差异版，不只交零散替换句。
2. 核对改写前后关键数字、单位、置信区间、方向、术语、结论强度和文献归属。
3. 摘要、正文与图表存在矛盾时回到权威分析核实，不能选更漂亮的一组数字。
4. 区分“文字已改”“作者已确认”“证据已核实”；生成一份修订稿不代表作者已接受全部修改。
5. 不清楚的事实集中到短待核清单，说明所在位置、缺少依据及对提交的影响，不在正文遍布工作提示。
6. 清稿进入 `03_Manuscript`，必要的差异版作为该目录内独立版本；不让旧稿、修订稿和投稿稿混名。
7. 进入投稿审核前检查全文读起来是否仍明确回答科学问题，且没有因润色遗漏阴性结果、研究局限或必要声明。
