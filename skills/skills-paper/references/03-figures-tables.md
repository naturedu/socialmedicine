# 第三步：图表制作与核对

在带图表位置的框架已经明确后读取本文件。目标是让每张图表回答一个具体问题，并能从数据、代码和图注追溯其内容。

## 1. 从既有图表开始

- 先找用户确认的图表、分析输出、制作脚本和源数据；记录各自版本及相互对应关系。
- 能用的已确认图先保留。修改只针对内容、证据或可读性上的具体问题，不因换期刊而无理由全盘重画。
- 区分统计结果图、概念机制图、流程图和描述表：它们的证据要求与制作方法不同。
- 无数据但需要框架时，可给结构示意和待填表壳；标清“示意／待核”，不能输出看似真实的估计值。
- 来源冲突时先定位：同名文件不代表同一数据版本；不能只凭文件日期认定权威版本。

为拟交付项目建立简洁台账：

| 图表编号 | 回答的问题 | 数据/证据来源 | 已确认版本 | 对标图与用途 | 正文位置 | 本轮改动 |
|---|---|---|---|---|---|---|
| Figure/Table 编号 | 一句话 | 文件、变量或文献位置 | 日期或版本 | 布局/统计表达/图例 | 章节与段落 | 保留/修改/新增 |

图数和表数由科学问题、结果结构和目标期刊限制决定，不强制固定数量。

## 2. 把“顶刊风格”落实到真实范图

1. 优先查看用户指定范文的原文和图注，再补充同刊、同文章类型或同统计任务的范例。
2. 记录论文题名、期刊、年份、DOI或原文链接、图号及实际查看范围；摘要不能作为完整图注的核验依据。
3. 提炼可迁移规则：面板顺序、坐标、列宽、数字列、图例位置、分组方式和信息密度。
4. 说明哪些特征适合当前数据。范图的效应量、研究设计和样本结构不同，不照搬统计表达。
5. 私人框架稿嵌入范图时，明确标注“版式参考，非本研究结果”及出处；公开发布或投稿前核对使用许可。
6. 正式研究图以本研究数据重绘；不能把范文图中的数值、趋势或样本特征当作本研究结果。

不要仅凭记忆声称某期刊统一要求某套配色、字体、分辨率或图表数量。实际投稿时查当期官方作者指南，并记录核验日期。

## 3. 先锁数据，再排视觉

- 明确分析单位、分母、缺失值、组别、结局定义、时间窗、单位及模型版本。
- 统计结果来自已执行的分析输出；排版脚本不得重新手填一套未经核对的估计值。
- 数值修正回到数据或分析层完成，再同步图、表、正文与补充材料；保存更正记录。
- 对重复受试者、多个结局、亚组或时间点，标明是否独立，避免把相关观察误作独立样本。
- 描述性表应让读者看懂研究对象、具体情境、暴露/干预 X 和结局 Y；避免只有缩写和代码。
- 样本量、事件数、百分比分母、效应方向、置信区间与 P 值使用同一分析口径。
- 真实缺失、零事件、不适用和未报告分别表示；不要统一写成 0 或空白。

## 4. 按问题选择表达

| 图表任务 | 要保留的信息 | 常见核查点 |
|---|---|---|
| 基线/研究特征表 | 分组、样本量、变量定义、分布及缺失 | 均值与标准差、中位数与四分位数不混用；是否需要 P 值依设计与期刊而定 |
| 效应量/森林图 | 效应类型、估计值、区间、参照与分组 | OR/RR/HR 与差值的无效线不同；需要时用对数轴；极宽区间不静默裁掉 |
| 系统综述森林图 | 研究标签、结局、估计量、区间、合并方法 | 权重、异质性和预测区间仅在方法支持且已计算时呈现；多结局不无说明混合 |
| 随访/生存图 | 时间起点、随访单位、组别与在险信息 | 删失标记、在险人数、累计发生与生存概率的含义一致 |
| 预测模型图 | 验证数据来源与性能维度 | 区分训练、内部验证、外部验证；校准、判别和决策价值分别解释 |
| 流程图/PRISMA | 各阶段对象、人数、排除理由 | 分支与总计可核对；不套用不匹配的模板；待核计数不伪装完整 |
| 地图 | 地理单位、指标、分母、覆盖与缺失 | 无研究地区不同于结果为零；国界与底图来源记录；不能用样本量替代患病率 |
| 机制/技术路线图 | 主体、变量、关系、步骤和证据层级 | 箭头含义明确；假设机制区别于已证实路径；避免用装饰遮住逻辑 |

图表不以显著性筛选展示内容；预设主要结局、关键阴性结果和必要的不确定性都应可见。

## 5. 制作与版式

- 统计图优先用可复现的 R 脚本；已有可靠 Python 或其他分析流程时延续其工具，不为换工具改变结果。
- 机制图、框架图保留 SVG、PPTX 等可编辑图源；“可编辑”须说明是文本、形状、图层还是仅可替换整张图片。
- 横向关系多时用横版，递进步骤多时可先试竖版。用户未指定时竖向流程可作初稿，最终按正文栏宽与阅读顺序调整。
- 优先清晰的文字层级和留白；减少重复标题、过量角标和不承载含义的装饰。
- 图内是否放标题取决于用途：正文已有完整图题时避免重复；独立分享版本可另设标题。
- 同一变量、组别和结局在整篇使用稳定颜色与名称；必要时增加形状或线型，避免只靠颜色辨识。
- 按最终单栏/双栏尺寸检查字号、线宽和密度，不能只看放大后的预览。
- 中文使用可用且覆盖完整的字体；英文、希腊字母、数学符号与上下标逐项查看。
- 表格采用可编辑表格，常规统计表默认三线表；复杂表按信息层级调整，不把三线表当所有期刊硬规则。
- 数字按列对齐并统一有效位数；置信区间、小数点、负号、乘号、百分号和统计符号一致。
- 依期刊规范设置统计符号斜体、上下标和单位；不要把所有希腊字母或计量单位机械设为斜体。
- P 值报告方式服从分析与期刊规范；避免把计算精度限制写成 P = 0。
- 跨页表重复表头，防止表题、脚注、续表与数据行错位；不以截图替代应可编辑的表。

## 6. 图注与表注能独立阅读

图注至少解释研究对象/数据集、指标、分组、单位、样本量口径，以及图中误差条或阴影代表什么。

- 多面板图逐个说明 A、B、C 的含义及比较关系。
- 写明效应量类型、参考组、调整模型或对应方法位置；不要只写“调整后结果”。
- 说明缩写、符号、缺失标记、统计检验及必要的多重比较处理。
- 地图、改绘框架或外部素材保留来源与许可说明；图形美化不消除引用义务。
- 表格脚注定义统计量、单位和分类；明确各百分比的分母，区分行百分比和列百分比。
- 图注不得新增正文与方法没有支持的因果解释，也不把探索性分析写成预设验证。

## 7. 三层验收

**数据层：** 以脚本输出或已确认汇总表逐项核对样本量、事件数、估计值、区间、方向、分组与单位。

**文稿层：** 核对摘要、正文、图表、图注和补充材料的相同数字；每张图表都有正文引用，编号按首次出现顺序且无孤立附件。

**视觉层：** 打开最终导出文件，以投稿尺寸查看裁切、重叠、缺字、断行、轴标签、数字列和清晰度；嵌入 Word/PDF 后再检查分页与缩放。

结构检查不等于视觉检查。没有打开导出预览时，明确说明视觉核验尚未完成，不写“图表全部检查通过”。

## 8. 交付与进入下一步

- 每张图保留源代码/可编辑图源、作图所用数据或其索引、正式投稿导出及图注。
- 导出格式、尺寸、色彩模式和分辨率按目标期刊当前要求，不硬编码一套通用数值。
- 代码须给运行入口与必要依赖；未执行的脚本标为未运行，不称可复现成功。
- 正文中的图表保留在 `03_Manuscript`；单独上传所需图源/导出放该目录的 `figures` 子目录，补充图表放 `04_Supplementary`。
- 原始数据和分析依据归入本轮约定的 `00_原始数据`，涉及敏感数据时交付本地索引或获准的数据版本，不擅自公开。
- 图表台账标注已核实、待核或不适用，并说明具体问题和影响。实质数字冲突未解决时可继续文字整理，但不能将投稿包标为可提交。
