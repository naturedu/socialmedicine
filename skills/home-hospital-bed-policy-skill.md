# 🏡 家庭病床：把连续医疗服务送到居住场所

## 一、概念与边界

2026年《家庭病床服务指南（试行）》将其界定为由医疗机构对符合条件、就医存在困难且需要连续服务的患者，在居住场所开展并记录诊疗、康复和护理等服务的形式。它有医疗机构、评估、建床与病历管理要求，不能把所有上门服务都记作家庭病床。见[国家指南官方转载](https://wsjk.ln.gov.cn/wsjk/zfxxgk/zc/gjjwj/2026052921070163217/index.shtml)。

| 概念 | 研究时抓住什么 | 不能直接等同 |
|---|---|---|
| 家庭病床 | 建床、责任团队、连续治疗、记录、撤床 | 一次上门护理 |
| 居家医疗 | 医疗服务的场所与可及性 | 一定已建立病床 |
| 互联网+护理 | 线上线下衔接的护理供给方式 | 一定有医保支付或家庭病床资格 |
| 家庭医生签约 | 长期健康服务关系与履约 | 签约即持续接受家庭病床服务 |
| 长期护理保险 | 失能照护的筹资与待遇制度 | 家庭病床全部费用都由长护险承担 |

国外hospital-at-home研究的收治病情、服务强度与支付模式可能不同，做文献迁移前重新对齐PICO与服务定义。

## 二、读文件要有层次

先读[2020老年人居家医疗通知](https://www.nhc.gov.cn/wjw/c100175/202012/740e7b5f686c447797e6b1e02ae163e2.shtml)，理解居家供给；再读2026家庭病床指南，提取服务与质量流程；支付部分追溯[医保发〔2026〕7号及其解读](https://www.nhsa.gov.cn/art/2026/3/16/art_105_19933.html)。国家服务指南与地方价格、医保结算文件需要联合阅读，不能只拿一篇服务指南推断全国报销比例。

指南署名日期为2026-05-11；公开目录列示的发布日期与地方转载日期可能不同。建库应分别记录签发、发布、生效、地方配套和机构开办日期；未核到生效日就保留缺失。

## 三、服务链的逻辑框架

**识别需求 → 申请 → 机构综合评估 → 知情同意与协议 → 建床/团队服务 → 动态监测 → 转诊或撤床 → 费用结算与质量评价。**

国家指南涉及评估、服务频次、记录、转诊等环节；研究者可以据此提出过程指标，但“文件写有流程”与“机构实际完成流程”应分别测量。

## 四、条款与数据提取矩阵

| 维度 | 文本编码 | 可能关联的数据 |
|---|---|---|
| 对象资格 | 病情、连续治疗需求、就医困难、场所条件 | 诊断、功能、居住与交通、照护支持 |
| 机构与人员 | 许可、科目、团队、资质、容量 | 开办机构、服务半径、医护工时 |
| 服务内容 | 查床、检验采样、护理、康复、药学、安宁等 | 实际项目、次数、间隔与团队构成 |
| 过程质量 | 首次访视、定期查床、记录、告知、风险处置 | 时间戳、病历完整度、转诊响应 |
| 建撤床 | 申请、评估、协议、周期、转诊、撤床标准 | 建床日期、持续时间、退出原因 |
| 支付 | 项目价格、医保范围、结算、个人负担 | 基金支付、现金支出、服务/交通成本 |
| 衔接 | 家医、上级医院、养老机构、长护险 | 转诊网络、重复付费、服务断点 |

这是研究建议字段，不是所有地区现成数据库都包含。就医困难也可能与严重度共同影响服务使用，不能用“接受家庭病床服务者”与全体未服务者直接比较。

## 五、地方案例与制度差异

[上海医保局2026家庭病床费用问答](https://ybj.sh.gov.cn/cb_jbdyl/20260629/1e69bab8735e46bba0876130dd2f81aa.html)给出特定参保类型的支付口径，可用于地方文本案例；此比例不能外推到居民医保、其他省市或所有上门项目。[湖北养老服务条例](https://mzt.hubei.gov.cn/fbjd/zcwj/zcfg/202603/t20260301_5882457.shtml)可作为省级制度衔接样本，但条例中的支持方向不能替代具体医保结算细则。

## 六、研究问题与方法

候选问题：是否改善行动不便者的医疗可及性；是否替代部分住院/急诊而不增加风险；是否减轻交通与照护负担；机构的服务半径与支付激励如何影响供给。这些均是待检验问题。

有分期机构/区域实施可考虑现代DID；有足够长月度过程指标可考虑ITS/CITS；个体服务开始策略可在TTE框架下设计；供给容量、路程与排班可考虑DES/微观模拟。安全事件和死亡等竞争结局、选择进入与退出、机构聚类及同时政策要预先处理。

不要只报“住院少了”：可能是服务替代，也可能是风险选择、就医障碍或记录变化。健康、安全、患者体验、家庭负担与总社会成本应共同评估。

## 七、交付与易错点 🐾

交付国家—地方文件树、概念对照表、建撤床流程、文本编码表、变量字典和评价设计。费用口径区分建床、上门、医疗项目、设备与照护；服务量分清患者、床日、访视与项目，避免把一人多次服务当多个患者。

> 可复制请求：请按服务链解释家庭病床，与居家医疗/上门护理/家医/长护险逐项区分。核对国家指南和地方支付细则，提取责任、频次、费用、建撤床与转诊条款，再提出可识别的效果评价方案。
