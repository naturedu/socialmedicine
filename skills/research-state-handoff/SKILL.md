# 研究接续摘要

适用于恢复长任务、整理项目状态或为新对话准备上下文。先定位最近有效成果，再补读决定其状态的证据；标题列表不算已读历史。只处理用户授权范围，不顺带归档聊天或删文件。

用[接续模板](references/handoff-template.md)生成一份摘要。删除重复播报、过时计划和无效尝试全文，保留影响决策的失败原因。区分“生成了文件”“运行验证通过”“内容经人工确认”“已发布”，不能相互替代。

必须保留目标及范围、已接受的约束、权威版本、关键决定与依据、验证范围、未完成事项及下一步。引用本地证据位置；未知内容明确标记，不从文件名推断完成状态。

摘要中的真实路径和研究细节仍属项目资料，默认留在本地。公开技能另写通用方法，不公开这份摘要。压缩摘要不会减少已有聊天的历史上下文；是否开启新对话或归档旧对话由用户要求决定。
