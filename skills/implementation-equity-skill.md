# 🌼 实施与公平：有效的服务，也要有人能用上

## 概念到变量

主动健康和HiAP可提供跨部门行动方向；研究仍需定义谁采取什么行动、通过什么机制、让谁获得什么改变。把“数智赋能—协同治理—健康改善”展开成可测链条：信息可达→服务响应→转诊/随访完成→患者负担→健康结果。每条箭头分别说明理论或证据，不能仅靠结构方程显著就证明全部机制。

## 框架如何分工

- **CFIR**：梳理干预、外部/内部环境、个体与实施过程的障碍和促进因素；选与问题相关的构念，避免把所有条目都放进访谈。
- **RE-AIM**：关注触达、效果、采纳、实施与维持，提前规定分母、层级和时间窗。
- **实施结局**：可接受性、适切性、可行性、依从/忠实度等，与临床/人群健康结局分别测量。
- **公平视角**：比较触达、获益、负担与排除；总体平均改善可能伴随弱势群体差距扩大。

使用时对照框架官方资源核对版本：[CFIR](https://cfirguide.org/)、[RE-AIM](https://re-aim.org/)。本Skill是研究设计路线，不替代具体量表的信效度验证。

## 定性—定量整合

先用访谈/观察识别组织协同中的具体行为，再以有定义的指标测量。联合展示表一行一个机制：定性证据、定量指标、分析结果、相符/矛盾之处与替代解释。扎根产生的构念不应在同一批材料中被宣称“独立验证”；解释结果也不能只挑支持预设框架的引文。

## 公平性最小指标

```r
# 教学数据：0/1结局且均值>0；fractional rank按收入从低到高
d <- data.frame(income=c(1,2,3,4,5),use=c(0,0,1,0,1))
n <- nrow(d)
d$r <- (rank(d$income,ties.method="average")-.5)/n
mu <- mean(d$use)
cov_pop <- mean((d$use-mu)*(d$r-mean(d$r)))
CI <- 2*cov_pop/mu
Erreygers <- 4*mu*CI # 仅适用于0/1界限；未加权教学表达
c(CI=CI,Erreygers=Erreygers)
```

正式分析应纳入复杂抽样、经济排序并列及区间估计；报告结局编码方向。利用不平等不等于需求标准化后的不公平；CI与健康结果差值也不是相互替代的指标。集中指数分解、PAF及健康影响评估继续读旗舰HiAP和速查C8。

## 交付与易错点 🐾

输出逻辑模型、构念—变量表、分母/时间窗、访谈codebook、联合展示、异质性与公平性分析。不要把框架拼接数量当创新；不要给自行构造的协同指数贴上“已验证”标签；不要把访谈频次直接当人群患病率。

> 可复制请求：请把我的政策目标拆成实施与健康两类结局，选择合适的CFIR/RE-AIM构念，写测量与联合展示方案，并检查哪些人可能未被触达。
