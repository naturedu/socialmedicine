# 科研教学、方法科普与分镜PPT

## 从学习目标组织

先确定听众看完能做什么：识别适用设计、解释图表、执行关键步骤或检查常见错误。按“为什么需要—核心直觉—适用条件—小例子—操作—误区”组织，按材料灵活合并；不要把论文摘要直接分成数页。

## 社医卫管方法示例

DID用政策前后与对照比较解释，强调平行趋势与处理时点；Markov用状态和转移解释，说明时间步与模型假设；目标试验模拟用方案表与time zero解释；机器学习区分训练、验证、校准与应用。所有演示数字显著标注教学示意，不放进正式研究结果。

理论图解保留原始理论名称与出处。个人讨论框架不冒充经验证的学术理论。术语首次出现做中英对照，口播可简化但不能改变统计含义。

## 分镜与媒介

分镜表至少包含页面/时间段、画面、主句、图解、口播、来源与转场。人物画面、字幕安全区、进度条和双语字幕只在实际视频任务中加入；当前只做PPT时不擅自扩展为剪辑发布。

手机图解与投影PPT分别预览，细密原图可拆解为局部并保留出处。插画或可爱风用于降低理解成本，不能挤占关键文字。配色、字号与人物风格按本次要求选择，不把一次偏好固化为通用规则。

## 可直接使用的任务书

```text
请将这个研究方法做成教学PPT与分镜。先设定听众需要掌握的能力，再按问题、直观解释、例子、操作、误区组织；公式和例子保留正确口径。区分真实研究与教学示意，提供逐页口播、图解、来源和导出检查。
```

## 交付与衔接

需要的材料：教学主题与已有材料；受众基础、时长和使用媒介；需要讲清的概念与案例。

交付：教学PPT或图解卡片；逐页口播与分镜表；来源、概念核对与导出说明。

通用交付检查见[画图与PPT质量检查](figure-ppt-quality-skill.md)，工具与来源边界见[公开工作流来源说明](references/visual-skill-sources.md)。涉及期刊尺寸、格式或生成服务时，执行前核对目标官方文档。
