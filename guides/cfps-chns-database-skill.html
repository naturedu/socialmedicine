📚 CFPS、CHNS与NHIS · 扩展调查选型

核验日期：2026-10-23。综合家庭、营养社区和年度健康访谈的单位、时间、权重与分析路线。

本次核验层级

这三项为官方文档/入口补充，未确认本机个体文件版本。CFPS已核对官方申请指南；CHNS已读取官方问卷目录但数据主站本次抓取受限；NHIS核对CDC年度资料入口。不把资料入口存在写成“已上传并清洗”。

CFPS：先理顺个人与家庭

成人、少儿、家庭成员与家庭经济文件按单位分开。个人追踪键、当轮家庭键和跨轮家庭关系分别核对；分户、婚迁及家庭重组会改变家庭构成。先做每波键唯一性与连接率，检查人→家庭多对一而非盲目m:m。收入、消费、健康、教育和认知的实际题体与可用轮次由代码本确认。

研究家庭资源与健康可用个体/家庭面板，但家庭固定效应的单位不能随分户悄悄改变。政策DID需授权地区与实际时点；公开匿名地区代码是否跨期稳定要查文件，不凭数值自行解码。儿童、成人与家庭经济权重不能互换。

CHNS：把食物记录放回正确层级

膳食数据可能是人—日—食物条目，家庭食物记录和社区指标又是其他单位。先按代码本处理食物代码、重量、能量/营养素来源、在家/外食、调查日数，再预先定义个体日均或其他指标。未记录与未进食不同；极端能量摄入规则预定并保留敏感性，不能为显著性反复删值。

不能把每天多条食物记录当很多独立个人；先汇总研究单位，再与健康表连接。社区变化与个体迁移区分；跨年食物成分表、调查地区扩展和抽样代表范围要查原文。CHNS营养关联的单位和暴露误差与NHANES饮食回顾不同，不能照搬同名营养变量。

NHIS：年度访谈与设计断点

按年度数据说明选择成人、儿童或其他组件；只合并分析所需文件与权重。普通年度文件主要用于相应人群横断面/趋势估计；不能按相似ID把年度受访者伪造成重复观察。问卷重新设计、访谈模式及样本变化应在趋势中标记。死亡链接需按NCHS独立文档核对资格、连接键和随访，不从未出现于次年文件推断死亡。

选库规则

家庭代际和教育机制优先检查CFPS题体；营养和社区环境优先检查CHNS；美国访谈健康/保障年度趋势检查NHIS；客观健康检查与实验室指标检查NHANES；长期医疗费用研究可看MEPS。先证明存在所需暴露、结局、时间和抽样支持，再选模型。

🧺 先把数据放进正确的小篮子

建立文件清单：study / release / module / wave / visit_date / unit / key / source / permission。文件名中的版本字母、下载年份和访谈波次分开。原始文件只读；另存标准化层和分析层。先输出字段名、标签、值标签、缺失码和连接诊断，再决定变量能否使用。

每个分析变量至少记录：概念、原题、来源变量、适用人群、回顾窗口、单位、跳答路径、特殊码、代理回答、派生公式、可用波次、权重及核验状态。不得只凭中文列名判断值域或方向；weight在多份表中是体重。

从问题到估计的顺序

  1. 写清目标人群、暴露/政策、比较组、结局和时间零点。区分人群患病比例、个体内变化、预测准确性和政策效应。
  2. 画样本流：原始入样→年龄/资格→完成访谈→完成测量→连接随访→分析样本。死亡、失访、跳题、拒答、未测量分别记，不统一改成0。
  3. 描述研究所需字段在每波的可用性。两波数据最多支持一次变化；多波轨迹需要足够重复观测、可比较测量与合理类数。
  4. 按估计目标选择横断面、纵向或特定组件权重；权重不能凭变量名相似借用。失访加权需要可解释的响应模型和正值性诊断。
  5. 面板FE估计的是个体内关联；PSM不能消除未测混杂；交错DID还需真实政策起始、前期趋势和有效对照；TTE需对齐资格、分组及随访起点。
  6. 保留未加权人数、加权估计与区间。重复测量、家庭和地区依赖按设计处理；缺失值插补与抽样设计的结合需写明方法，避免把插补当作增加独立样本。

交付与报告

交付版本清单、变量字典、跨波可用矩阵、连接诊断、样本流、缺失/失访表、模型脚本和执行记录。公共教程仅包含方法与元数据；获准数据留在授权环境。问卷存在某题、当前文件有字段、分析样本有有效观测是三个不同层次。

相关路线：纵向研究、PSM/加权、分批DID、目标试验模拟、计量模型。R/Stata代码为接口模板，本次未在这两个运行时执行。

官方出处与版本边界

  • CHNS 官方问卷目录：调查模块与题体入口；主站本次抓取受限。
  • CDC NHIS：年度家庭健康访谈、数据及问卷入口。
