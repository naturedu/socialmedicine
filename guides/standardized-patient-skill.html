模拟与标准化病人：把服务过程变成可比较的证据

标准化病人（standardized patient, SP）通常由经过训练的人按剧本稳定呈现病史、行为和反应；模拟病人（simulated patient）在文献中有时与之互用。这里强调可重复呈现和测量一致性。它不是 Markov 微观模拟，也不是让大模型生成“真实患者”。

1. 先选研究用途

用途 主要问题 能测量什么 不能直接声称什么
教学、沟通训练与OSCE 学员在统一情境下如何表现 问诊、沟通、决策和程序表现；按站点评分 考场表现等于长期真实临床表现
告知式服务评估 机构在知道评估存在时怎样服务 统一情境的质量与流程 不存在观察反应
未预先告知标准化病人 USP 常规服务中的实际行为如何 适当处置、询问检查、转诊、费用及沟通 覆盖所有疾病、重症体征和后续健康结局
标准化病例/临床情境问卷 医务人员“知道该怎么做” 知识或陈述决策 与USP测得的实际行为完全相同

ASPE 标准主要面向人类模拟教学与评估；USP 质量研究还需研究方案、抽样、识别与安全管理。先确定对象、场景、主要结局、比较与时间窗，再选是否适合 SP。[S1–S3]

2. 剧本与评分表怎样制作

选择可安全、可信地呈现且与研究问题相关的场景。明确开场陈述、只有被问到才提供的信息、允许的标准回答、情绪与行为、不可模拟的体征，以及何时停止访问。临床处置评分应由相应专业人员依据适用指南制定，注明指南日期与评分规则；本站不提供自行施行检查或治疗的脚本。

评分表逐项定义“应询问/应检查/应处置/不适当操作”、信息来源、缺失、不适用和分母。主要结局应预先规定，例如符合预定处置标准的访问比例；不能看完结果才挑最显著条目。复杂综合分数需说明权重和测量依据，不能自动视为已验证量表。

先做小规模可行性试演：对同一剧本重复训练，检查扮演者间与扮演者内一致性、评分者一致性及回忆遗漏。二分类可考虑一致率与κ，连续分数按设计考虑ICC；同时查看分布，因为高一致率与低κ可能并存。

3. 抽样、分配与访视安排

  1. 写清机构抽样框、纳排、地区与服务类型。便利样本不代表全国质量。
  2. 若评价干预，明确随机化或政策分配单位；机构层分配不能把每次访问当作独立随机单位。
  3. 记录医生、机构、扮演者、剧本、访问时间与重复访问关系。角色和案例尽量在比较组平衡；同一医生重复访问及跨机构SP可形成多层或交叉结构。
  4. 事先做功效规划：主要结局、预期差异、机构数、每机构访问数、ICC、病例构成与不可完成比例。增加同一机构访问数不能无限替代增加机构数。
  5. 在许可范围内尽快填写结构化访问记录；若使用音频等材料，必须与批准方案、访问授权和保存期限一致。

4. 伦理与安全是设计条件

未预先告知不等于不需伦理审查。医务人员同意的取得方式或豁免、事后说明、隐私与声誉保护、对正常服务的干扰，须由相应伦理审查与机构安排明确。授权或豁免只能由适用程序认定，不能由本工具自动决定。[S1–S3]

预设不得接受的侵入性检查、真实用药与危险情境及退出流程；出现超出模拟范围的情况应中止并按批准的安全流程处理。保护SP的身体与情绪安全，安排训练、支持和复盘。公开结果以适当聚合形式呈现，不发布可识别的个人访问记录。

5. 数据字典与质量核查

下载SP字段模板。模板是空白字段说明，不含患者或医务人员记录。

核心字段：匿名机构/医生/访问/扮演者/案例ID，组别与实际分配，访问时间，各评分项目及分母，主要处置结局，费用，是否被识别，剧本偏离，不完整访问及缺失原因。

保留访视失败和识别记录。识别可能与机构、剧本或干预有关；仅删除“被识别”样本可能引入选择偏倚。主分析与敏感性分析的对象、分母和排除标准均提前规定，并报告各阶段数量。[S2]

6. 分析如何排布

  • 先描述抽样、完成率、案例分布、识别比例和评分缺失。
  • 二元结局报告比例与区间，并明确风险差、风险比或OR；不把OR直接解释成风险比。
  • 机构随机研究按分配单位处理相关性。脚本/演员固定或随机、平衡程度与目标总体决定采用机构汇总、多层或交叉模型。
  • 横断面USP比较主要支持描述与关联；只有满足随机或准实验识别条件才能作相应因果解释。
  • 观察真实患者资料与SP资料回答不同问题：病例标准化有利于比较，却不代表实际患者疾病谱与长期结局。[S2–S3]

下方例子为36个随机分组机构，每机构3个案例×4位扮演者，共432次模拟访问。案例和扮演者在机构间完全平衡，采用等机构权重的组间比较；推断限于这组案例和扮演者。R脚本已在R 4.6.1运行；Stata为未执行教学模板。模拟结果不保证显著，也不是任何真实政策效果。

7. 与实施科学怎样联用

例如评估基层指南落实：同一临床服务对应两种实施支持策略，机构分组，USP评估处置过程质量，另用实施数据衡量采纳、忠实度、成本与维持。SP评分属于服务过程质量，不能替代全部实施结局或患者健康结局。明确盲法、识别风险、策略污染及机构聚类，再判断是否适合 hybrid 设计。实施科学路线

机构层级分析 · R

下载脚本

# Original teaching simulation. No patient data and no clinical recommendations.
# Balanced cases/actors at every clinic; inference is conditional on this set.
set.seed(20261024)
clinics <- data.frame(clinic_id=1:36, arm=sample(rep(0:1, each=18)))
visits <- merge(clinics, expand.grid(case_id=1:3, actor_id=1:4))
clinic_effect <- rnorm(36, 0, 0.45)
p <- plogis(-0.55 + 0.5*visits$arm + clinic_effect[visits$clinic_id] +
             c(-0.2,0,0.2)[visits$case_id])
visits$correct <- rbinom(nrow(visits), 1, p)
visits$detected <- rbinom(nrow(visits), 1, 0.07)
stopifnot(nrow(visits)==432, all(table(visits$clinic_id)==12))
clinic_scores <- aggregate(correct ~ clinic_id + arm, visits, mean)
# Clinic allocation means visits are not independent trial units.
comparison <- t.test(clinic_scores$correct[clinic_scores$arm==1],
                     clinic_scores$correct[clinic_scores$arm==0])
rd <- unname(diff(rev(comparison$estimate)))
stopifnot(abs(rd - (mean(clinic_scores$correct[clinic_scores$arm==1]) -
                   mean(clinic_scores$correct[clinic_scores$arm==0]))) < 1e-12)
print(data.frame(estimand='Equal-clinic mean risk difference (arm 1 minus 0)',
                 estimate=rd, lower=comparison$conf.int[1], upper=comparison$conf.int[2]))
# Detection is reported, not silently deleted; exclusions may select on treatment.
print(aggregate(detected ~ arm, visits, mean))
print(aggregate(correct ~ arm + case_id, visits, mean))
# For observational samples these contrasts are descriptive, not causal effects.
# Unbalanced scripts/actors, few clusters, or cross-classified random actors need
# a prespecified adjustment model and suitable uncertainty estimation.
stopifnot(all(visits$correct %in% 0:1), all(is.finite(comparison$conf.int)))
cat('PASS: 432 visits; 36 randomized clinics; balanced scripts; finite clinic-level interval\n')

* Original teaching simulation; not run in Stata in this release.
clear all
set seed 20261024
set obs 36
gen clinic_id = _n
gen allocation_order = runiform()
sort allocation_order
gen arm = (_n > 18)
gen clinic_effect = rnormal(0, .45)
expand 12
bysort clinic_id: gen visit = _n
gen case_id = mod(visit-1,3)+1
gen actor_id = ceil(visit/3)
gen p = invlogit(-.55 + .5*arm + clinic_effect + .2*(case_id-2))
gen correct = (runiform() < p)
gen detected = (runiform() < .07)
assert inlist(correct,0,1)
assert _N == 432
tabstat detected, by(arm) stat(mean n)
* Equal clinic weighting; case and actor assignments are balanced by construction.
preserve
collapse (mean) correct, by(clinic_id arm)
assert _N == 36
regress correct i.arm, vce(robust)
lincom 1.arm
restore
* The individual-visit model is an alternative, not an independent replication.
regress correct i.arm i.case_id i.actor_id, vce(cluster clinic_id)
lincom 1.arm

* separate design-based decisions. Do not delete detected visits without a plan.
