任务书与交付

先写决策问题、视角、目标人群、时间尺度、政策情景、状态/事件、干预作用点和校准目标。参数表记录单位、来源、估计误差、相关性及可迁移性。给出可执行的最小模型后再扩展，不凭空增加行为机制。

校准使用部分观测目标约束未知参数，验证尽可能使用独立时期/地区/结局。拟合与验证同一批数据只能说明内部重现；多个参数组合都拟合良好时应讨论不可辨识。按 AHRQ模型指南 组织模型透明度和验证说明。

一个很小的R排队实验

set.seed(20261023)
n <- 1000
arrival <- cumsum(rexp(n,rate=4))
service <- rexp(n,rate=5)
start <- finish <- numeric(n)
for(i in seq_len(n)){
  start[i] <- max(arrival[i],if(i==1) 0 else finish[i-1])
  finish[i] <- start[i]+service[i]
}
wait <- start-arrival
c(mean_wait=mean(wait),p95_wait=unname(quantile(wait,.95)))

这里是假定单服务台、指数到达/服务、先到先服务的教学模型；一次运行不能给出可靠政策比较。正式应用要核对时间单位、到达率稳定性、多个服务台、优先级、暖机期、独立重复与区间。

个体微观模拟的详细入口

需保留病史、个体异质性和竞争事件时，使用个体微观模拟技能。包含痴呆/衰弱及慢病应用对照、R教学实现、Stata模板、MCSE与PSA边界。

健康经济连接

若目标为成本效果，模型还需累计成本、效用、生存与贴现，再按参数联合分布做PSA；若比较资源排队，拥堵反馈可能让简单队列Markov不足。详见Markov、卫生经济及蒙特卡洛Skill。先检查模型边界是否覆盖决定性机制，再决定复杂度。

小心这几个坑 🐾

把拟合叫验证；用任意规则生成“政策一定有效”的结论；只报一次运行；忽视资源容量与跨主体干扰；把结构不确定性压缩成参数置信区间；画了复杂流程却没有可执行的事件与状态规则。
