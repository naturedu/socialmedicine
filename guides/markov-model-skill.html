Skill：Markov 模型助手（卫生经济学成本-效果分析，Stata / R）

版本 1.0 · 作者 杜思娴 (Du Sixian) · 许可 MIT · 更新 2026-10-23

用途

一份可复用的「Markov 模型（队列模拟）」成本-效果分析（CEA）工作流：从健康状态定义、转移概率的来源与估计（率 → 概率换算）、转移矩阵构建、成本与效用参数设定，到 Stata / R 的队列模拟（含半周期校正与 3% / 5% 贴现）、ICER 计算与阈值比较、单因素（tornado）与概率敏感性分析（PSA），再到结果报告与模型校验。每一步都给出「方法 + 代码」（Stata 与 R 双实现，R 侧另给 heemod 包的等价写法）。全程使用同一示例：高血压 / 卒中预防干预（常规治疗 vs 强化降压干预；3 个状态、1 年周期、30 年时间范围），所有代码为可直接运行的具体示例、数值自洽。既可作为提示词喂给大语言模型，也可作为操作手册照做。

适用范围（明确边界）

允许： - 帮助社会医学与卫生经济学研究者完成 Markov 队列模型的 CEA 全流程（药物、筛查、慢病管理等干预的建模） - 给出率 → 概率换算、转移矩阵构建、半周期校正、贴现、ICER / NMB、tornado 与 PSA 的方法与 Stata / R 代码 - 用 heemod（R）、Mata（Stata）等工具复现与交叉验证同一模型

不允许： - 替研究者决定状态结构、转移概率、成本与效用取值及临床假设（需临床专家、流行病学与卫生经济学证据支撑） - 承诺模型结果一定可发表；不替代《中国药物经济学评价指南（2020）》、ISPOR-SMDM 建模良好实践与教科书（如 Briggs et al. 2006）及期刊审稿要求 - 在没有参数来源、没有做模型校验（face validity、极端值检验）的情况下直接给出结论

软件准备

方法：Stata 17 及以上（本 Skill 只用内置命令与 Mata，无需安装外部包）；R ≥ 4.2 + heemod（CRAN；heemod ≥ 1.0 的新版 API，贴现通过 discount() 写入状态值）。PSA 绘图用基础 R 即可；矩阵幂（可选）用 expm。

工作流程总览（8 步）

  1. 定义健康状态与模型结构 → 2. 转移概率的来源与估计 → 3. 构建转移矩阵 → 4. 成本与健康效用参数 → 5. 队列模拟（半周期校正 + 贴现） → 6. 计算 ICER 与阈值比较 → 7. 敏感性分析（tornado + PSA） → 8. 报告与校验。以下每一步均为「方法 + 代码」。

第 1 步：定义健康状态与模型结构

方法：

  • 健康状态：互斥（mutually exclusive）、穷尽（collectively exhaustive）、有临床意义，且各状态的成本 / 效用应明显不同。本示例（卒中预防干预）设 3 个状态：① 无并发症（未发生卒中）；② 卒中后；③ 死亡（吸收态）。
  • 周期长度：与干预作用与疾病自然史匹配，慢性病常用 1 年（急性期模型可用 3 个月或 1 个月）；周期内至多允许一次事件，若事件密集需缩短周期或改用微模拟。
  • 时间范围（horizon）：足够长使队列绝大部分进入吸收态，通常 30–40 年或至 100 岁；本例取 30 年（敏感性分析可作 40 年）。
  • 起始分布：本例 100% 处于「无并发症」（trace = (1, 0, 0)）；其他研究可按年龄 / 分期分布设定。
  • 队列规模：按 1 人（比例）模拟，结果按「每人」报告；也可乘 1000 等人数。

第 2 步：转移概率的来源与估计

方法：

  • 来源：① 已发表模型（引用并做币值 / 时间通胀与周期长度换算）；② RCT / 队列的生存分析（Kaplan-Meier → 参数生存模型：指数 / Weibull / Gompertz，指数假设下年率 r = −ln S(t)/t）；③ 疾病登记与生命表（背景死亡按年龄别生命表）。
  • 率 → 概率换算（周期 t，率与 t 单位一致）：p = 1 − exp(−r·t)；反向：r = −ln(1 − p)/t。不同周期长度换算：p_t = 1 − (1 − p_1)^t。
  • 注意：年发生率 0.02 ≠ 年概率 0.02（正确值 0.0198）；率越高二者差异越大。同一状态多个竞争事件先合并率再换算，或在离散框架内用「互补出对角线」保持行和为 1。
  • 示例数值：卒中年发生率 0.02 → 概率 0.0198；干预使卒中风险降 30%（RR = 0.70）→ 率 0.014 → 概率 0.0139；卒中后死亡年率 0.10 → 概率 0.0952；无并发症背景死亡概率 0.010（生命表）。

代码：

* Stata：率 → 概率（t 为周期长度，按年）
display 1 - exp(-0.02*1)        // 卒中年发生率 0.02 → 年概率 = 0.0198013
display 1 - exp(-0.10*1)        // 卒中后死亡年率 0.10 → 年概率 = 0.0951626
display 1 - exp(-0.02*0.5)      // 半年概率 = 0.0099502
* 概率 → 率（反向）
display -ln(1 - 0.0198013)/1
* 由 5 年生存率 0.80 反推年率与年死亡概率（指数生存假设）
display -ln(0.80)/5             // 年死亡率 = 0.0446287
display 1 - exp(-(-ln(0.80)/5)) // 年死亡概率 = 0.0436481
* 周期长度换算：1 年概率 0.0198013 → 3 个月（1/4 年）概率
display 1 - (1-0.0198013)^(1/4)

# R：同样的换算

1 - exp(-0.10*1)                    # 0.09516258
-log(1 - 0.01980133)                # 概率 → 率
S5 <- 0.80
r_annual <- -log(S5)/5              # 5 年生存率反推年率
1 - exp(-r_annual)                  # 年死亡概率
# 周期长度换算

第 3 步：构建转移矩阵

方法：行 = 周期初状态，列 = 周期末状态；每行和为 1；死亡为吸收态（死亡行 = (0, 0, 1)）；对角线用「1 − 行内其余项」计算以保证行和恒为 1。构建后用 rowsum / rowSums 校验，并用矩阵幂检查 20 年后的状态分布（非负、和为 1）。

代码：

             0.0000000, 0.9048374, 0.0951626 \ ///
             0.0000000, 0.0000000, 1.0000000)
matrix list PA, format(%9.4f)

第 4 步：成本与健康效用参数

方法：

  • 成本：按研究视角（本示例为卫生体系视角，直接医疗成本）。示例：无并发症年成本 3000 元；干预追加药费 500 元/年（即干预组无并发症年成本 3500 元）；卒中后年成本 20000 元；死亡成本 0。可另加一次性事件成本（卒中急性期），本例从简。
  • 效用：EQ-5D 等偏好基础工具测量（优先中国人群值集）。示例：无并发症 0.85、卒中后 0.62、死亡 0；QALY = Σ 状态效用 × 生存时间。
  • 区间：无区间时常用点估计 ±20%（结构式敏感性分析）；有 95% CI 时按 CI 边界。由均值 / CI 反推 PSA 分布参数的矩法：beta（均值 m、标准差 sd）：α = m·(m(1−m)/sd² − 1)，β = (1−m)·(m(1−m)/sd² − 1)；gamma：shape = m²/sd²，scale = sd²/m；lognormal：sdlog = (ln UL − ln LL)/(2×1.96)。

代码：

* Stata：由均值 / 区间反推 PSA 分布参数（矩法）
* beta：效用 0.85、sd 0.03 → alpha、beta
display 0.85*(0.85*(1-0.85)/0.03^2 - 1)          // alpha ≈ 119.57
display (1-0.85)*(0.85*(1-0.85)/0.03^2 - 1)      // beta  ≈ 21.10
* gamma：成本 3000、sd 600 → shape、scale
display 3000^2/600^2                              // shape = 25
display 600^2/3000                                // scale = 120
* lognormal：率 95% CI [0.015, 0.03] → sdlog
display (ln(0.03) - ln(0.015)) / (2*1.96)         // sdlog ≈ 0.177

# R：同上（矩法）
beta_mom  <- function(m, sd) { k <- m*(1-m)/sd^2 - 1; c(alpha = m*k, beta = (1-m)*k) }
gamma_mom <- function(m, sd) c(shape = m^2/sd^2, scale = sd^2/m)
beta_mom(0.85, 0.03)                     # alpha 119.57, beta 21.10
gamma_mom(3000, 600)                     # shape 25, scale 120
(log(0.03) - log(0.015)) / (2*1.96)      # sdlog 0.177

第 5 步：队列模拟（cohort simulation）

方法：

  • 核心迭代：trace(t+1) = trace(t) × P。数据行 1 为起始分布；行 _n（n = 1..T）即第 n 个周期的期初状态分布，配权重 1/(1+d)^(n−0.5)。
  • 奖励累积：每周期成本 = Σ 状态人数 × 状态年成本；QALY 同理（死亡状态成本 / 效用为 0）。
  • 半周期校正：假设事件在周期内均匀发生，用 (t−0.5) 的指数权重近似（相当于把期初计数折到周期中点）；不做校正会系统性高估成本与效果（本例约高 2.4%，即 ×√(1+d)）。
  • 贴现：《中国药物经济学评价指南（2020）》要求成本与效果同率贴现，基例 5%，另作 3% 情景（本 Skill 同时给出 5% 与 3% 两套结果；敏感性分析可再加 0%）。

5.1 Stata 纯循环（完整代码）

* ============ 第 5 步：队列模拟（Stata 纯循环） ============
local T = 30                     // 时间范围（年/周期）
* 策略 A：常规治疗
local p_hs1 = 1 - exp(-0.02)     // 无并发症→卒中（率 0.02/年）
local p_hd1 = 0.010              // 无并发症→死亡
local p_sd1 = 1 - exp(-0.10)     // 卒中后→死亡（率 0.10/年）
local c_well1 = 3000             // 无并发症年成本
local c_sick1 = 20000            // 卒中后年成本
local u_well1 = 0.85             // 效用
local u_sick1 = 0.62
* 策略 B：干预（卒中风险降 30%）
local p_hs2 = 1 - exp(-0.02*0.70)
local p_hd2 = 0.010
local p_sd2 = 1 - exp(-0.10)
local c_well2 = 3500             // 无并发症年成本 + 500 元药费
local c_sick2 = 20000
local u_well2 = 0.85
local u_sick2 = 0.62

matrix R = J(0, 4, .)            // 收集两策略结果：成本/QALY × (5%, 3%)

forvalues s = 1/2 {
    * ---- 状态占位（行 1..T+1；行 1 为起始分布） ----
    clear
    set obs `=`T'+1'
    gen healthy = .
    gen sick    = .
    gen dead    = .
    replace healthy = 1 in 1       // 起始：100% 无并发症
    replace sick    = 0 in 1
    replace dead    = 0 in 1
    * ---- 转移循环：trace(t+1) = trace(t) × P ----
    forvalues t = 2/`=`T'+1' {
        replace healthy = healthy[`t'-1]*(1-`p_hs`s''-`p_hd`s'') in `t'
        replace sick    = healthy[`t'-1]*`p_hs`s'' + sick[`t'-1]*(1-`p_sd`s'') in `t'
        replace dead    = dead[`t'-1] + healthy[`t'-1]*`p_hd`s'' + sick[`t'-1]*`p_sd`s'' in `t'
    }
    * ---- 每周期成本与 QALY（期初状态） ----
    gen cost_cyc = healthy*`c_well`s'' + sick*`c_sick`s''
    gen qaly_cyc = healthy*`u_well`s'' + sick*`u_sick`s''
    * ---- 贴现 5%：半周期校正权重 1/(1+d)^(n-0.5)，只累加第 1..T 周期 ----
    gen w05 = 1/(1+0.05)^(_n-0.5) if _n <= `T'
    gen cost05 = cost_cyc*w05
    gen qaly05 = qaly_cyc*w05
    qui sum cost05
    local c05_`s' = r(sum)
    qui sum qaly05
    local q05_`s' = r(sum)
    * ---- 贴现 3%（敏感性情景） ----
    gen w03 = 1/(1+0.03)^(_n-0.5) if _n <= `T'
    gen cost03 = cost_cyc*w03
    gen qaly03 = qaly_cyc*w03
    qui sum cost03
    local c03_`s' = r(sum)
    qui sum qaly03
    local q03_`s' = r(sum)
    * ---- 30 年死亡比例（行 T+1 的 dead） ----
    local d30_`s' = dead[`=`T'+1']
    matrix R = R \ (`c05_`s'', `q05_`s'', `c03_`s'', `q03_`s'')
}
matrix rownames R = A B
matrix colnames R = cost5 qaly5 cost3 qaly3
matrix list R, format(%12.2f)
display "30 年死亡比例：A = " %6.4f `d30_1' "；B = " %6.4f `d30_2'
* 期望输出：A: cost5≈63186.10, qaly5≈10.7716；B: cost5≈63913.00, qaly5≈11.1113
*           A: cost3≈80062.67, qaly3≈13.1935；B: cost3≈80588.47, qaly3≈13.6758
*           30 年死亡比例：A≈0.4894，B≈0.4314

5.2 R 从头实现（完整代码）

# ============ 第 5 步：队列模拟（R 从头写） ============
T <- 30
p_hsA <- 1 - exp(-0.02)          # 无并发症→卒中（对照）
p_hsB <- 1 - exp(-0.02*0.70)     # 无并发症→卒中（干预）
p_hd  <- 0.010                   # 背景死亡
p_sd  <- 1 - exp(-0.10)          # 卒中后死亡
PA <- matrix(c(1-p_hsA-p_hd, p_hsA, p_hd,
               0,           1-p_sd, p_sd,
               0,           0,      1), nrow = 3, byrow = TRUE)
PB <- matrix(c(1-p_hsB-p_hd, p_hsB, p_hd,
               0,           1-p_sd, p_sd,
               0,           0,      1), nrow = 3, byrow = TRUE)

# 队列模拟：trace(t+1) = trace(t) %*% P；奖励按周期期初状态、权重 1/(1+d)^(t-0.5)
sim <- function(P, c_well, c_sick, u_well, u_sick, dr, T = 30) {
  trace <- matrix(0, nrow = T + 1, ncol = 3)
  trace[1, ] <- c(1, 0, 0)                      # 起始：100% 无并发症
  for (t in seq_len(T)) trace[t + 1, ] <- trace[t, ] %*% P
  w   <- 1 / (1 + dr)^(seq_len(T) - 0.5)        # 半周期校正 + 贴现权重
  cyc <- trace[seq_len(T), ]                    # 第 1..T 周期的期初分布
  cost <- sum((cyc[, 1] * c_well + cyc[, 2] * c_sick) * w)
  qaly <- sum((cyc[, 1] * u_well + cyc[, 2] * u_sick) * w)
  c(cost = cost, qaly = qaly, p_dead = trace[T + 1, 3])
}

resA5 <- sim(PA, 3000, 20000, 0.85, 0.62, 0.05, T)
resB5 <- sim(PB, 3500, 20000, 0.85, 0.62, 0.05, T)

第 6 步：计算 ICER

方法：

  • ICER = ΔC / ΔE =（干预成本 − 对照成本）/（干预 QALY − 对照 QALY）。
  • 阈值：《中国药物经济学评价指南（2020）》以 1–3 倍人均 GDP 作为阈值参考区间（2020 年中国人均 GDP ≈ 7.2 万元；用研究当年最新统计，本例取人均 GDP ≈ 10 万元 → 阈值区间 10 万–30 万元/QALY）。ICER < 1×GDP：极具成本效果；1–3×：具成本效果；> 3×：不具成本效果。
  • ICER 象限与决策规则（ΔC 为纵轴、ΔE 为横轴）：
  • 东北（ΔC>0, ΔE>0）：更贵更有效 → ICER < λ 采纳，≥ λ 拒绝；
  • 东南（ΔC<0, ΔE>0）：更便宜更有效 → 占优（dominant），采纳；
  • 西北（ΔC>0, ΔE<0）：更贵更差 → 被占优（dominated），拒绝；
  • 西南（ΔC<0, ΔE<0）：更便宜更差 → ICER（为正）> λ 时采纳（每节省的钱高于损失 QALY 的价值），≤ λ 拒绝。
  • 负 ICER 不能直接按数值比大小，必须先判象限；ΔE ≈ 0 时 ICER 不稳定，改用净货币效益 NMB = λ·ΔE − ΔC（NMB > 0 采纳）。

第 7 步：敏感性分析

方法：

  • 单因素（tornado）：每个参数单独取低 / 高值（±20% 或 95% CI 边界），其余固定，重算 ICER；两臂共用的参数（背景死亡、卒中后死亡、卒中后成本、效用）两臂同步变动。按 ICER 变化范围排序作图；负值表示该情景下落入占优或其他象限，报告中注明符号含义。
  • PSA 分布选择依据：概率参数（0–1）→ beta；率与 RR（>0）→ lognormal（R 用 rlnorm / exp(rnorm)，Stata 用 exp(rnormal)）；成本（>0，偏态）→ gamma；效用（0–1）→ beta。参数由第 4 步矩法给出。循环 1000 次蒙特卡洛，输出 ΔC–ΔE 散点图与 CEAC（P(ΔC − λ·ΔE < 0) 对 λ 的曲线）。

capture mata mata drop markov_ce()
mata:
real colvector markov_ce(real scalar phs, real scalar phd, real scalar psd,
                         real scalar cw, real scalar cs,
                         real scalar uw, real scalar us,
                         real scalar d, real scalar T)
{
    real matrix  P, trace, cyc
    real colvector w, c, q
    P = ((1-phs-phd, phs, phd) \ (0, 1-psd, psd) \ (0, 0, 1))
    trace = J(T+1, 3, 0)
    trace[1, 1] = 1
    for (t = 1; t <= T; t++) trace[t+1, .] = trace[t, .] * P
    w   = 1 :/ (1+d) :^ ((1::T) :- 0.5)
    cyc = trace[1..T, .]
    c   = colsum((cyc[,1]*cw + cyc[,2]*cs) :* w)
    q   = colsum((cyc[,1]*uw + cyc[,2]*us) :* w)
    return((c \ q))
}
end

* ============ 第 7.2 步：PSA（Stata：rbeta/rgamma/rnormal 循环） ============
* 分布依据：概率→beta；率/RR→lognormal（exp(rnormal)）；成本→gamma；效用→beta

set seed 2026
local N = 1000
local T = 30
matrix PSA = J(0, 4, .)                    // 每行：cA qA cB qB
forvalues i = 1/`N' {
    * ---- 参数抽样 ----
    local p_hsA = 1 - exp(-exp(rnormal(ln(0.02), 0.20)))
    local p_hsB = 1 - exp(-exp(rnormal(ln(0.02), 0.20))*exp(rnormal(ln(0.70), 0.10)))
    local p_hd  = rbeta(24.74, 2449.26)
    local p_sd  = 1 - exp(-exp(rnormal(ln(0.10), 0.15)))
    local cA0   = rgamma(25, 120)
    local cB0   = `cA0' + rgamma(25, 20)
    local cS    = rgamma(25, 800)
    local uW    = rbeta(119.6, 21.1)
    local uS    = rbeta(57.8, 35.4)
    * ---- 对照臂队列模拟（同第 5.1 步循环） ----
    clear
    set obs `=`T'+1'
    gen healthy = .
    gen sick = .
    gen dead = .
    replace healthy = 1 in 1
    replace sick = 0 in 1
    replace dead = 0 in 1
    forvalues t = 2/`=`T'+1' {
        replace healthy = healthy[`t'-1]*(1-`p_hsA'-`p_hd') in `t'
        replace sick    = healthy[`t'-1]*`p_hsA' + sick[`t'-1]*(1-`p_sd') in `t'
        replace dead    = dead[`t'-1] + healthy[`t'-1]*`p_hd' + sick[`t'-1]*`p_sd' in `t'
    }
    gen w = 1/(1+0.05)^(_n-0.5) if _n <= `T'
    gen cA_c = (healthy*`cA0' + sick*`cS')*w
    gen qA_c = (healthy*`uW'  + sick*`uS')*w
    qui sum cA_c
    local cA_t = r(sum)
    qui sum qA_c
    local qA_t = r(sum)
    * ---- 干预臂队列模拟 ----
    replace healthy = 1 in 1
    replace sick = 0 in 1
    replace dead = 0 in 1
    forvalues t = 2/`=`T'+1' {
        replace healthy = healthy[`t'-1]*(1-`p_hsB'-`p_hd') in `t'
        replace sick    = healthy[`t'-1]*`p_hsB' + sick[`t'-1]*(1-`p_sd') in `t'
        replace dead    = dead[`t'-1] + healthy[`t'-1]*`p_hd' + sick[`t'-1]*`p_sd' in `t'
    }
    gen cB_c = (healthy*`cB0' + sick*`cS')*w
    gen qB_c = (healthy*`uW'  + sick*`uS')*w
    qui sum cB_c
    local cB_t = r(sum)
    qui sum qB_c
    local qB_t = r(sum)

}

plot(lam_grid, ceac, type = "l", xlab = "阈值 λ（元/QALY）",
     ylab = "具有成本效果的概率", main = "CEAC")
abline(h = 0.5, lty = 3); abline(h = 0.95, lty = 3)
# 期望（示意）：本示例各阈值下 P(CE) > 0.99，P(占优) ≈ 0.36；
# heemod 集成版 PSA 见 vignette("e-probabilistic", "heemod")（define_psa + run_psa）

第 8 步：报告与校验

方法：

  • 结果表：两策略并列报总成本、总 QALY，再报 ΔC、ΔE、ICER，注明贴现率与阈值；本示例（5% 贴现）ICER ≈ 2,140 元/QALY < 10 万元，结论为「极具成本效果」。
  • ISPOR-SMDM 建模良好实践要点（Caro et al. 2012）：① 概念模型——明确问题、视角、人群、干预、时间范围，状态互斥穷尽且有临床意义；② 结构假设——简化需合理并与临床路径一致；③ 数据——参数识别、估计与来源透明，换算（率→概率、币值/时间通胀）记录在案；④ 一致性与质量——内部一致性（行和、极端值、半周期校正、与独立实现交叉验证）与 face validity；⑤ 不确定性——单因素 + PSA，报告分布与相关性假设；⑥ 报告透明——按 CHEERS 2022 清单完整披露。
  • 模型校验清单：face validity（临床专家确认状态、箭头方向与量级）；内部一致性（行和 = 1；极端值：卒中率 → 0 时两臂相同、死亡率 = 1 时第 1 周期后全灭、效用全 1 时 QALY = 贴现生命年）；交叉验证（Stata / R / heemod 结果互相印证，差异仅为贴现时点约定）；外部验证（与已发表模型或登记数据对照）。

代码（极端值检验；Stata 调用第 7.1 步的 markov_ce()）：

mata:
// ① 卒中率 → 0：两臂 QALY 应完全相同
markov_ce(0, 0.010, 1-exp(-0.10), 3000, 20000, 0.85, 0.62, 0.05, 30)[2]
markov_ce(0, 0.010, 1-exp(-0.10), 3500, 20000, 0.85, 0.62, 0.05, 30)[2]
//   期望输出：两值相同（≈ 12.0320）
// ② 卒中率 = 0 且死亡率 = 1：第 1 周期后全灭，仅剩第 1 周期奖励
markov_ce(0, 1, 1, 3000, 20000, 0.85, 0.62, 0.05, 30)
//   期望输出：cost ≈ 2927.70（3000×0.9759），qaly ≈ 0.8295（0.85×0.9759）
// ③ 效用全 = 1：QALY 应等于贴现生命年（≈ 13.0549）
markov_ce(1-exp(-0.02), 0.010, 1-exp(-0.10), 0, 0, 1, 1, 0.05, 30)[2]
end

常见错误清单

  • [ ] 把「率」直接当「概率」用（0.02/年 ≠ 0.02；正确 p = 1 − exp(−0.02) ≈ 0.0198；率越高偏差越大）
  • [ ] 转移矩阵行和 ≠ 1（对角线应 = 1 − 行内其余项；死亡行必须为 (0, 0, 1) 吸收态）
  • [ ] 忘记半周期校正（权重用了 (t−1) 而非 (t−0.5)，系统性高估成本与效果约 ×√(1+d)）或重复校正
  • [ ] 贴现只贴成本不贴效果（指南要求成本与效果同率贴现；敏感性另做 0%/3% 情景）
  • [ ] 循环次数与时间范围不一致（T 个周期需 T 次转移、数据 T+1 行；奖励只累加第 1..T 行）
  • [ ] 「期初 vs 期末」状态取值与权重错位（第 t 周期的奖励必须配第 t 周期期初的状态行）
  • [ ] ICER 解读错误：ΔE < 0 时把负 ICER 直接比大小；应先判象限（东南占优 / 西北被占优 / 西南用「ICER > λ 才采纳」规则）
  • [ ] ΔE ≈ 0 时仍报告 ICER（数值不稳定），应改用 NMB = λ·ΔE − ΔC
  • [ ] PSA 分布选错：概率用 normal（可能 < 0 或 > 1）、成本用 normal（可能 < 0）、RR 用 gamma / 率用 beta（应 lognormal / beta）
  • [ ] R 的 rgamma() 忘记写 scale =（默认第二参数是 rate，结果量级全错）
  • [ ] Stata rgamma(a, b) 与 R 参数含义不同（Stata 第二参数是 scale，R 是 rate）——两边代码已按各自语法写对，移植时勿混用
  • [ ] R matrix(..., byrow = TRUE) 忘记 byrow 导致矩阵转置（行和检查仍会通过，但模型方向全错）
  • [ ] 时间范围太短（队列尚未进入吸收态），成本与效果被截断
  • [ ] 忘记 set seed / set.seed，PSA 结果不可复现
  • [ ] 参数无来源、无区间、无分布依据；不做 face validity 与极端值检验
  • [ ] Stata：replace 的范围（in 行号）写错只更新了一行；循环边界差 1（T 个周期要循环到第 T+1 行）；矩阵追加忘记 J(0, k, .) 初始化
  • [ ] heemod：run_model 未指定 effect = utility；未用 method = "life-table" 却说做了半周期校正；dispatch_strategy 的策略名与 run_model 的名字不一致

使用提示

  • 命令与选项随版本更新：Stata 运行 help matrix / help forvalues / Mata 手册核对；R 侧 help(run_model)、help(discount)、help(define_transition) 核对 heemod API（本 Skill 按 heemod ≥ 1.0 新版 API 编写，贴现写在 define_state 的 discount() 中）。
  • 贴现与半周期校正的约定（期初计数 + (t−0.5) 权重）必须写进报告；与 heemod 等其他软件对照时先统一贴现时点与 method 约定，再比较结果。
  • 转移概率在代码中一律用精确值计算（行和自动为 1），表格只展示 4 位小数。
  • 阈值用研究当年最新人均 GDP 的 1–3 倍区间，并配合 CEAC 报告，而非只做单点比较。
  • 本 Skill 提供方法与代码模板；状态结构、参数取值与临床假设由研究者依据证据确定并负责。
