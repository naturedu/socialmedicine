🧰 卫生计量模型：先看问题和数据，再打开工具箱

六步逻辑框架

  1. 目标：描述、预测、因果还是资源决策？先定义目标人群、时间窗与待估量。
  2. 结局：连续、正偏费用、含零费用、计数、二元/有序、多分类、时间至事件还是比例？
  3. 结构：独立横断面、重复横断面、个体面板、多层聚类、复杂抽样还是空间关联？
  4. 识别：随机、条件可交换、政策时点、阈值或有效工具变量？“多元回归”本身不是识别策略。
  5. 估计：选择与支持集、依赖结构和目标相符的模型/链接/权重。
  6. 检查与表达：诊断、绝对效应/边际效应、区间、敏感性、外推边界。

按结局选候选模型

结局 候选 核心解释与检查
近连续 OLS、稳健SE 条件均值、残差结构、函数形式、影响点
正偏且严格正的费用 Gamma-log GLM、适当变换模型 均值-方差关系、链接、拟合；log系数与原尺度效应不同
大量零费用+正费用 两部模型 使用概率×使用者费用；合并预测与区间
计数/率 Poisson、负二项 暴露人时offset；过度离散；均值设定与SE
零特别多的计数 hurdle、零膨胀等 是否有结构性零的实质机制，不按零比例自动决定
二元/有序/多分类 logit/probit、有序或多项模型 OR与风险比不同；比例优势/类别结构
连续分布不同位置 分位数回归 条件分位数效应；不能直接说个体被影响多少
生存 Cox、参数/AFT、竞争风险 删失、PH、时间尺度与目标风险

费用取对数后再简单指数还原通常不能直接得到原尺度条件均值；需考虑重转换与异方差。Gamma要求正值，不给零费用随意加1来“满足模型”。模型选择先看数据机制，再用诊断与验证比较，不能只按显著性或AIC下决定。

两部模型的R接口

# d: cost>=0，a为处理/分组，x为治疗前协变量
d$anycost <- as.integer(d$cost>0)
pmod <- glm(anycost~a+x,family=binomial(),data=d)
cmod <- glm(cost~a+x,family=Gamma(link="log"),data=subset(d,cost>0))
d1 <- d0 <- d; d1$a <- 1; d0$a <- 0
pred_mean <- function(nd) predict(pmod,nd,type="response") *
  predict(cmod,nd,type="response")
mean(pred_mean(d1)-pred_mean(d0))
# 这只是标准化模型差异；因果解释另需识别假设。
# 区间可对整个两部拟合与标准化过程适当重抽样；聚类数据按簇抽样。

glm cost i.a c.x if cost>0, family(gamma) link(log) vce(robust)
margins, dydx(a)
poisson visits i.a c.x, exposure(person_time) vce(robust)
qreg cost i.a c.x, quantile(.5)

Gamma代码只分析正费用者，不是完整两部人群效应；不能把此条件结果与全样本两部结果混为一谈。

面板FE、RE与CRE

FE利用单位内变化控制时间不变的单位差异；无法估计不随时间变化且被单位效应吸收的变量。RE还要求对个体效应与解释变量关系作更强假设。CRE/Mundlak通过纳入时间变化协变量的个体均值描述相关结构，允许区分部分组内/组间信息。不要只做一次Hausman检验就宣称某模型正确。

xtset id year
xtreg y x i.year, fe vce(cluster id)
xtreg y x i.year, re vce(cluster id)
bysort id: egen xbar = mean(x)
xtreg y x xbar i.year, re vce(cluster id)

短面板的滞后因变量、反向因果和测量误差不能靠FE自动消除；动态面板GMM需检查矩条件、序列相关、工具数量与弱识别，不能把“用了GMM”当稳健性的标签。政策分批实施先读交错DID，而不是只在此回归上加一个post变量。

IV、RDD与空间模型

IV要论证相关性、排除限制、独立性及目标解释；弱工具诊断、稳健区间与推断比第二阶段P值更重要。过度识别检验不能证明所有工具有效。

ivregress 2sls y x (a=z), vce(robust)
estat firststage

RDD先核对精确运行变量、阈值、操纵与政策跳变，采用合理局部估计、带宽及稳健推断；阈值两侧病例“看起来相似”不够。年龄按整年记录可能不足以支持精细退休阈值设计。详见速查D2/D3。

空间模型从空间权重矩阵的实质含义出发；Moran's I、SAR/SEM/SDM与空间溢出各有角色。不要把普通回归的空间相关残差直接叫政策溢出；报告权重定义、孤立地区、尺度敏感性以及直接/间接效应。

报告与交付 🐾

交付“目标—结局—结构—识别—模型—诊断”表、公式、变量字典、分析样本、SE层级、边际预测及敏感性。报告完整效应尺度和区间；非线性模型的交互项系数不一定等于概率尺度交互效应。算法解决拟合，研究设计承担解释。
