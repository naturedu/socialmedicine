# 国社科正式立项数据与复现

更新：2026-10-24。入口：[国社科立项图谱](../nssfc-projects.html)。

从 22 份主管部门或高校官网来源文件、38 个年度批次提取 60,578 条公开立项元数据，筛入并去重后 4,471 个相关项目，涉及 726 个保留原层级的机构名称。其中 2,659 项命中卫生健康题名规则。所有公开记录均来自正式立项名单，4,190 项保留原名单批准号；其余原附件未列批准号，未补造。

## 纳入与覆盖

- 2016—2025 年重点、一般、青年全国批次已按正式名单条数核对，依次为 3,917、4,289、4,506、4,627、4,625、4,642、4,675、4,790、5,138、5,254 项。它们是全学科分母，不是本领域项目数。
- 西部项目取得 2016、2018—2025 年正式附件；2017 年完整正式名单仍有缺口。
- 重大项目取得 2016—2025 年年度批次；重大专项只取得 2023 年二十大精神、2026 年二十届四中全会精神两批。
- 后期资助取得 2016—2020、2024—2025 年所列附件。2021—2023 年及 2026 年尚未取得系统可核实的正式完整附件。
- 2026 年度重点、一般、青年名单的公示和用户提供但未核实的材料不计入；2026 年当前只收录正式重大专项中的领域命中项。教育学、艺术学、军事学单列和其他专项没有系统覆盖。
- `date` 表示项目年度，而非网页发布日期。例如 2024 年后期资助正式结果于 2025 年 1 月公布，仍按项目年度 2024 年归类。立项指当年公布状态，未逐条追溯后续撤项、变更和结项。

原有公示和未验证记录单独保存在 `data/archive/nssf-unverified-2026-10-23.json`，不进入正式立项检索、机构统计或热点分析。教育部目录独立保留原状态，不纳入国社科分析。

## 数据与解释

| 文件 | 内容 |
|---|---|
| `data/nssf-projects.json` / `.csv` | 正式立项领域记录，含原机构、官方学科、批准号、官网存档、附件及定位 |
| `data/nssfc-source-files.json` | 22 份文件的下载地址、官网公告或存档、SHA-256、条数核对值 |
| `data/nssfc-batches.csv` / `nssfc-coverage.json` | 逐年逐系列解析量、筛入量、题目略条数和缺口 |
| `data/nssfc-methodology.json` | 题名纳入、排除、受控主题和关键词的完整正则规则 |
| `data/nssfc-analysis.json` | 机构、主题、年度与可比时期的描述性统计 |
| `data/nssfc-institutions.csv` | 全部机构频次；仅统一 Unicode 全半角与首尾空白 |
| `data/nssfc-cooccurrence.csv` | 完整共现边表，至少共现 5 项；含 Jaccard |
| `data/nssfc-topic-changes.csv` | 2018—2020 对 2023—2025 年每千项全学科立项的主题频次变化 |
| `data/nssfc-analysis-report.md` | 机构、主题、热点汇聚、解释及来源的完整报告 |
| `data/nssfc-analysis-report.html` | 可在浏览器直接阅读、打印的完整分析报告 |

主题与关键词是本站按题名的受控词表标注，**不是官方关键词或学科认定**。机构按每个项目全计数，主题和关键词按项目文档频次计数，允许交叉。同一题名可以属于多个主题，主题数之和不能当作项目数。机构层级没有自动上卷到大学，历史校名也没有推定合并。

去重优先使用批准号；无批准号时使用项目年度、系列、题名、责任单位、首席专家组合。同题不同首席专家或单位保留独立项目。PDF 的合并单元格仅按相邻行及跨页延续恢复题名；原附件未公开的“略”“题目略”保留在覆盖分母中，无法判定领域，不进入题名筛选结果。

热点是题名的描述性汇聚，不是效应量 Meta 分析。共现剔除包含关系词对及“数字化/数字政府”的机械共现。Jaccard 为两个词的共现项目数除以至少包含其中一词的项目数。时期比较只使用全国条数核对完成的重点、一般、青年批次，分母为同期全学科正式立项总数；不混入覆盖不一致的西部、重大、后期和 2026 年记录。

泛用的“健康发展”不单独触发健康领域纳入；儿童、身心健康等人群表达及其他独立健康或公共治理主题按公开规则保留。关键词筛选仍有漏检和边界条目，不能声称三个领域的全部项目已穷尽。题名不能证明研究设计、效应或因果机制，机构频次不能替代质量排名或申报成功率。

## 复现

Python 依赖：`requests`、`pymupdf`、`xlrd`、`openpyxl`、`markdown`。不调用模型，不需要账号或密钥。下载缓存不提交到仓库；只下载清单中公开链接，校验 SHA-256，发生变化时停止，待人工复核后更新清单。

```text
python scripts/nssfc_extract.py --cache work/nssfc-cache
python scripts/build_nssfc.py --cache work/nssfc-cache/parsed
python scripts/build_data_bundle.py
python scripts/build_material_index.py
node --test tests/projects.test.mjs tests/nssfc.test.mjs
```

已有缓存时可用 `--offline` 提取。旧公告可能返回 404，来源表保留其原地址并显示仍可取得的官网附件或存档；来源不以搜索摘要替代附件正文。

本次更改还从网站页面中删除主理人介绍、个人致谢、邮箱与电话。项目名单中的公开负责人和原资料书目署名仍作为来源元数据保留。

## 独立技能包

`downloads/nssfc-project-synthesis.zip`包含SKILL.md、同版提取与分析脚本、依赖及来源清单。解压后可直接用技能目录中的脚本，第二步加`--output <结果目录>`将结果写到任务目录，无需复制教育部数据或整个网站。两个脚本均支持`--manifest`指定经核验的新清单。

开发维护时运行`python scripts/build_nssfc_promo.py`同步技能脚本、来源、压缩包、二维码和公众号静态正文；该开发脚本另需`qrcode`。封面与长图从对应静态HTML通过浏览器导出并人工核对。
